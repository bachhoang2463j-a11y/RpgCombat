### 2. 特效层叠复用不足——反击只是"普通斩击 + 血粒子"

当前 [`playPowerCounterEffect`](file:///D:/Project/RpgCombat/战斗前端-爬塔%20V4.3.html#L4424-L4456) 的全部视觉组成：

| 阶段 | 做了什么 | 实际效果 |
|:---|:---|:---|

| 命中瞬间 | `playSVGEffect(victimDom, 'slash')` | 复用普通斩击的红色对角线 SVG，400ms |

**核心问题**：蓄力阶段完全无效 → 没有预期（anticipation），缺乏张力积蓄 → 爆发瞬间对比感极弱。

## 二、业界打击感塑造体系（Industry Impact Feel Framework）

根据 Game Analytics、GDC 演讲及 Martin Jonasson & Petri Purho 的经典"Juice it or Lose it"理论，**打击感 = 预期 × 爆发 × 余韵**，需要在以下 5 个维度叠加冗余反馈：

### 核心公式

$$\text{Impact Feel} = \underbrace{\text{Anticipation}}_{\text{蓄力/预兆}} \times \underbrace{\text{Contact}}_{\text{命中瞬间}} \times \underbrace{\text{Follow-through}}_{\text{余波/残留}}$$

### 五维反馈叠加清单

| 维度 | 原则 | 强力反击当前状态 | 优化方向 |
|:---|:---|:---|:---|
| **1. 时间操控** | Hit Stop（顿帧）1-5帧 = 16~83ms | 120ms 但仅冻结粒子层 | 全局冻结 + 缩短至 80ms |
| **2. 镜头语言** | Screen Shake 短促 + 衰减 | ✅ 强度16，但 300ms 偏长 | 缩短至 180ms，使用指数衰减 |
| **3. 闪光/Tint** | 命中瞬间白闪 + 目标变红 | ❌ 完全没有 | 添加全屏白闪 + 目标 filter 变色 |
| **4. 粒子视觉** | 分层：冲击波 → 火花 → 残留物 | 仅有单层血粒子 | 三层叠加：冲击波 + 定向碎片 + 余火 |
| **5. 动作预兆** | Anticipation 蓄力 + 角色动作 | ❌ 蓄力动画是死代码 | 角色亮起 + 收缩 + 聚气粒子 |

> [!IMPORTANT]
> 关键设计原则：**短即是重（Short = Heavy）**。动画越快越短促，给人感觉越沉重有力。当前蓄力等待 400ms + 命中后再 sleep(300ms)，整个过程长达 700ms+，稀释了冲击感。业界推荐重击总时长控制在 **250~400ms 内爆发完毕**。

## 三、具体优化方案

### 3.1 修复死代码：补全 `@keyframes power-glow-pulse`

在 CSS `</style>` 前添加缺失的 keyframes 定义。但更重要的是，将蓄力改为更有力量感的实现：

#### [MODIFY] [战斗前端-爬塔 V4.3.html](file:///D:/Project/RpgCombat/战斗前端-爬塔%20V4.3.html)

**CSS 新增**（约 Line 520 附近）：
- 补全 `@keyframes power-glow-pulse`（红色脉冲光晕 + 缩放）
- 新增 `@keyframes power-counter-flash`（全屏白闪，80ms 闪烁后快速消退）
- 新增 `.power-counter-screen-flash` 类

### 3.2 重写 `playPowerCounterEffect` 函数

**时间轴重构**（当前 700ms+ → 优化至 350ms 核心爆发）：

```
时间轴：
0ms    ─── 蓄力：角色 scale(1.08) + 红色聚气粒子向角色汇聚
150ms  ─── 命中：全屏白闪(50ms) + 角色瞬移攻击位 + 顿帧 80ms
230ms  ─── 爆发：三层粒子(冲击波+定向血雾+碎片) + 屏幕震动(intensity:20, 180ms)
310ms  ─── 余韵：残留血迹粒子缓慢下沉 + 目标红色 tint 渐退
```

### 3.3 重写 `spawnPowerBurst` → `spawnPowerCounterBurst`

分三层叠加：
1. **冲击波圆环**：白色→红色的扩散环，80ms 内扩到最大并消失
2. **定向碎片**：以攻击者→受击者方向为主轴，120° 扇形喷射，速度更快(15~40)
3. **余火/血雾**：低速缓慢扩散的暗红粒子，持续 500ms，模拟余波

### 3.4 修复 hitStop 仅冻结粒子层的问题

当前 `fxEngine.hitStop` 只在 `CanvasFxEngine.update()` 中检查，**不会冻结 DOM 动画和 SVG 特效**。优化方案：
- 命中瞬间对 `battle-scene` 添加 `animation-play-state: paused` 或 `transform: scale(1)` 的硬定帧
- 或用 `document.body.classList.add('global-hitstop')` 配合 CSS 全局冻结

### 3.5 瞄准框缩小

> [!NOTE]
> 你提到"瞄准框太大"——当前 SVG slash 效果使用 `width: 100px; height: 100px` 的 viewBox。对比枪击效果只有 `60x60`。强力反击作为精准反击技，应当使用更紧凑的 **60~70px** 尺寸，配合更锐利的线条。

## 五、变更影响预估

| 改动 | 影响范围 | 风险 |
|:---|:---|:---|
| 补全 `@keyframes power-glow-pulse` | 仅影响 `.power-glow` 类 | 极低 |
| 重写 `playPowerCounterEffect` | 仅在防守者强力反击触发时调用 | 低 |
| 重写 `spawnPowerBurst` → `spawnPowerCounterBurst` | 仅在上述函数内调用 | 低 |
| 新增全屏白闪 CSS | 新增独立 CSS 类 | 极低 |
| hitStop 全局化 | 需要确认不影响其他 hitStop 触发场景 | 中等 |
