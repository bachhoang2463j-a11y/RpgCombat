# 曲线与运动

弯曲弹道、匀速飞行或弹头朝向需要补强时读取；普通局部爆散不必读取。

## 范围与现有能力

这是技术参考，不是新增的运行时模块，也不包含已验证的弧长 LUT 实现。
项目路径均相对仓库根目录：

- `tactics/src/vfx-primitives.mjs` 的 `bez(a, c, b, t)` 已提供二次贝塞尔求值，`flyOrb()` 与 SVG `trail()` 使用相同控制点。
- `trail()` 已用 `pathLength="100"` 和 dash-offset 推进光轨。归一化描边不要求先调用 `getTotalLength()`；确需实际路径长度时再测量。
- `flyOrb()` 目前按参数取点生成 WAAPI 关键帧。共享控制点保证空间路线相同，不代表弹头和光轨每一时刻都处于相同位置。

修改前核对当前实现；不要把已有能力再次列成待新增功能，也不要把本参考理解为要求改动所有弹道。

## 参数、距离与朝向分别处理

二次贝塞尔以起点 P0、控制点 P1、终点 P2 定义：

- 位置：`B(t) = (1-t)^2 P0 + 2(1-t)t P1 + t^2 P2`。
- 导数：`B'(t) = 2(1-t)(P1-P0) + 2t(P2-P1)`。
- 朝向：由切线分量计算 `atan2(dy, dx)`，再按素材自身的正向校准旋转角。

线性推进参数 `t` 通常不等于匀速推进距离；朝向准确与否取决于切线计算，不能用“非匀速”解释全部朝向问题。转折、尖点等几何条件须在具体轨迹中验证，不声称任意曲线都能直接套用同一朝向策略。

## 确实需要匀速时的实现思路

以下是算法步骤，不是 GameStudio 文档提供的现成代码：

1. 对同一条曲线取点，累计相邻点距离，形成参数与累计弧长的对应表（LUT）。这是折线近似，不是精确弧长。
2. 用演出进度得到目标距离；匀速用线性距离进度，有意加减速则把缓动作用于距离进度。
3. 查找目标距离所在区间，插值得到曲线参数，再用共享求值函数计算位置与切线。
4. 若弹头、SVG 光轨与 Canvas 拖尾需要逐帧贴合，共用距离映射和时间进度，而不是各自配置一套缓动。

采样精度由实际曲率、速度和视觉结果决定，不预设未经测量的统一段数或“几十行即可完整落地”的工时承诺。

## 接入项目

- 通过 `tactics/src/vfx-host.mjs` 解析世界美术坐标；不要把屏幕像素和世界坐标混在一条轨迹里，也不要重复叠加相机变换。
- 复用现有特效作用域与 `tactics/src/time-scale.mjs` 演出时钟，不另建独立真实时间运动循环。
- 保留演出和规则结算的分离；到达、取消、重开时的结束与清场继续走现有宿主。

## 实现后的验证点

- 在直线、弯曲和多段连接轨迹中检查速度是否符合设计，朝向是否贴合切线。
- 检查弹头与光轨的空间路线和时间进度，而不只核对起终点。
- 检查镜头移动、倍速切换和重开清场；未经这些验证，不标记为可直接复用的原语。
