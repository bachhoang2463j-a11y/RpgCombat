# SVG 技能特效制作（svg-skill-vfx）

## 为什么存在
一次真实失败：用户给了"木火大招【青莲离火变】、木系群攻【碧影千叶杀】"，agent 只问了风格和音效，就按"单体 SVG 挂在目标上"做——结果大招像普攻，用户评价"简陋"。追加"全屏 + 明确蓄势"后才满意。
**根因：没对齐"量级"和"作用范围"。** 技能名里的"大招/群攻"是量级信号，必须翻译成可执行参数，不能默认成轻量单体。

---

## 一、先对齐需求（动手前必做）

### 1. 从技能名/标签自动推断草案
| 信号 | 推断量级 | 默认范围 | 默认蓄势 | 总时长 |
|---|---|---|---|---|
| 普通/普攻/弹/斩 | L1 轻量 | 目标局部（≤200px） | 无 | 0.4–0.6s |
| 控制/缚/封/定 | L2 中量 | 目标周身 + 地面 | 0.2–0.3s 起手 | 0.8–1.2s |
| 群攻/千/万/阵 | L3 重量 | **全屏** | **0.8–1.2s** | 2–2.5s |
| 大招/终极/变/诀/奥义 | L4 史诗 | **全屏 + 暗场** | **1.2–1.6s** | 3–3.5s |

### 2. 用 `ask_question` 一次问清（推荐项放首位，按草案预选）
必问 5 项（每项 2–4 选项）：
1. **量级与范围**：每个技能属于 L1–L4 哪档？是否全屏？（逐技能列出草案让用户改）
2. **蓄势表现**：法阵展开 / 灵气汇聚 / 蓄力环收缩 / 无蓄势
3. **爆发主体意象**：一个"占满屏幕的主图形"是什么（巨莲/通天火柱/剑痕风暴/天雷…）
4. **美术风格**：水墨写意 / 华丽光效 / 暗黑毁灭 / 赛博全息
5. **音效**：复用现成专业游戏音效（推荐，支持裁窗微调，个人娱乐项目首选）/ Web Audio 极轻辅层兜底
可选：命中段数、是否要书法技能名横幅、是否要暗场；若为实体状态/被动反馈演出，确认是否仅锚定单位本体而不联动无关 UI 栏位。

### 3. 交付形态
默认先出**独立 Demo HTML**（直接交付用户实机看，免测免审），确认后再移植主工程。

## 二、大招感的核心公式

> **大招感 = 时间上的"憋"(蓄势) × 空间上的"满"(全屏) × 感官上的"多"(层数+音画震)**

### 三幕时间轴（L3/L4 必须完整）
| 幕 | 占比 | 目的 | 手段 |
|---|---|---|---|
| ① 蓄势 | 35–45% | 让玩家"知道要来大的" | 暗场、巨型法阵缓转放大、粒子从屏幕四边吸入、蓄力环反复收缩、光核长大、持续轻震、音调上扬 |
| ② 爆发 | 10–15% | 一瞬间释放全部张力 | 全屏闪白、主图形超出屏幕、十字/通天光柱、粒子爆散、重震 + 低频轰鸣 |
| ③ 余韵 | 40–50% | 让画面"留住" | 花瓣/叶片雨、多段命中飘字、墨晕扩散、钟鸣尾音、暗场渐退 |

**关键：爆发前一刻要"收"**——蓄势末尾声音骤停/光核缩到最小（Hitstop 80–200ms），对比越强爆发越炸。

### 七层叠加模型（由底到顶，L4 至少用 6 层）
1. **暗场 Vignette**：`position:fixed; inset:0` 径向黑幕，opacity 0→0.8
2. **环境色罩**：技能主色半透明 tint（木=绿、火=橙、雷=紫）
3. **巨型法阵**：SVG，尺寸 = `max(innerWidth, innerHeight) × 1.1`，符文/刻度/太极，缓转
4. **主图形**：爆发时占满并超出屏幕（巨莲、剑痕、火柱），`scale` 超调后回弹
5. **光束/剑痕**：贯穿全屏的横纵线性渐变条，`scaleX/scaleY` 从 0 瞬开
6. **Canvas 粒子**：`mix-blend-mode:screen`，吸入/爆散/雨落三种运动；自定义形状（花瓣/叶/火星/墨晕/波纹环）
7. **UI 反馈**：书法技能名横幅 + 印章、多段伤害飘字、目标硬直闪色、技能卡锁定

## 三、技术工具箱（仅现代前端）

| 效果 | 实现 |
|---|---|
| 全屏层 | `fsLayer(html, ms)`：append 到 body 的 `fixed inset-0` div，`setTimeout` 自动移除 |
| 锚定目标 | 取 `getBoundingClientRect()` 中心，子元素 `left/top` + `translate(-50%,-50%)` |
| 灵气吸入 | `setInterval` 每 40ms 在屏幕外圆周生成粒子，速度指向目标，`drag≈0.965` |
| 叶片绕场收束 | 维护 orbit 数组（角度/半径/角速度），每帧半径 × `(1 - k*0.75)`，角速度 × `(1 + k*3)` |
| 主图形 | 循环生成贝塞尔花瓣 `M0,0 C-w,-.4L -.8w,-.85L 0,-L C...`，多层不同长度错角叠加 |
| 光柱 | `linear-gradient(90deg, transparent, 色 25%, #fff 50%, 色 75%, transparent)` + `scaleX` 动画 |
| 剑痕横扫 | CSS 变量 `--a` 旋转 + `translateX(-60vw→60vw)`，多条错开 delay |
| 震屏分级 | light 0.18s / heavy 0.32s / quake 0.5s，`translate3d`，蓄势期 `setInterval` 轻震 |
| 合成音 | 通用 `tone(type,f0,f1,dur,vol,delay)`；蓄势 = 多振荡器上扬；爆发 = 140→28Hz 低频 + 锯齿撕裂 + 528Hz 钟鸣 |
| 技能名横幅 | 毛笔刷底（`clip-path` 不规则多边形）+ 渐变文字 `background-clip:text` + 朱印 |
| 卡片流光 | `@property --ang` + `conic-gradient` 旋转边框 |

### 美术质感、真实音效与实体精准锚定纪律
- **禁止简陋几何线条，重过渡辉光与粒子特效**：
  - 严禁裸用空心虚线椭圆、纯色多边形线框、硬边锯齿折线或实色十字星充当特效主体。
  - 光束、裂纹、光盾与残影必须组合 **SVG 羽化辉光滤镜（`feGaussianBlur` + `feMerge`）**、**多层渐进描边（宽外晕 + 亮白/主色内芯）**、**`radialGradient`/`linearGradient` 柔边光晕** 与 **Canvas 发光粒子（`glowOrb` 柔光球、`bloom` 扩散光团、`spark` 飞星等）**。
- **音效优先选用现成专业游戏音效（个人娱乐项目，拒绝突兀合成音）**：
  - 优先复用项目现成音频映射或本地专业音效素材，按需裁剪标准化并配合声道定位（`pan`）、微调倍速（`rate`）与窗口淡出（`maxDurSec` / `fadeOutSec`）播放；Demo 可内嵌 Base64 离线直响，正式版接入预载池。Web Audio 合成音仅作为资源缺失时的极轻兜底或细微辅助，不得反客为主。
  - **同类复用与音量分级**：已有代表音色的系统演出直接复用原音（如怪物狂暴咆哮直接复用【嘲讽】`taunt.mp3`；盾反/荆棘反伤使用专业金属防反音效如 `parry_Shield3.wav`）。L1 高频短反馈音量显著低于 L2–L4 转折爆发与主攻击音效（短反馈约 `0.22~0.38`，转折爆发约 `0.50~0.75`）。
- **实体精准锚定与状态演出边界**：
  - 锚定单位时**严禁框选包含血条/Buff徽章的外层整卡容器**导致出现浮空矩形框；须剔除血条与状态栏计算真实主体视觉矩形（如我方取 `.portrait`、敌方计算视觉包络 `entityVisualRect`）。
  - 复制碎片/壳片/残影（`cloneVisualOnly`）须过滤血条/徽章/飘字等子 DOM，并按父容器实际缩放比（如后排 `scale(0.72)`）对齐尺寸。
  - 状态/被动触发演出优先在实体本体周身闭合完成（如【连动】直接于本体闪烁紫光残影表现极速抢攻），不跨屏干扰行动轴等无关 HUD（除非用户明确要求 UI 联动）。
  - 失色/碎壳/常驻光晕等状态变化须保持角色本体可见且可辨识，收尾彻底清除临时样式并允许安全重入，绝不残留永久遮罩。
- **双轨运动同源同步**：
  - 当 SVG 贝塞尔光轨与 Canvas 粒子轨迹同场飞向目标时，必须使用共享控制点的贝塞尔求值函数（`flyBezier(a, ctrl, b)`），严禁一方自定义曲率、另一方按默认垂直挑高 `fly()` 计算造成轨道分离。

### 性能纪律
- 主动画只动 `transform/opacity`，加 `will-change`；`filter/brightness` 用 `steps(1)` 离散跳变
- 渐变/滤镜 id 加 `uid` 防并发冲突；所有 DOM 定时回收
- Canvas `dpr` 封顶 2；粒子按 life 衰减后 `splice`
- 演出期间锁技能卡，防连点叠加

- [ ] 每个技能的量级/范围/蓄势是否已与用户对齐（不是我默认的）？
- [ ] L3/L4：蓄势 ≥ 0.8s 且肉眼明确？爆发前有"收"？
- [ ] L3/L4：主图形和光束是否超出屏幕？是否用了暗场？
- [ ] 音、画、震三者在爆发帧是否同步？是否已优先选用真实/专业游戏音效并控好 L1 低于 L2–L4 音量？
- [ ] 多段命中飘字 + 最后一段最强？
- [ ] L1 普攻与被动短反馈是否克制（≤0.6~0.9s、不全屏），以衬托大招与转折？
- [ ] 实体状态演出是否精准锚定立绘视觉本体（无包含血条的浮空大框）、不遮死头像且收尾无残留？
- [ ] 全场是否杜绝了生硬线框/粗折线，采用渐变辉光 + 粒子叠加，且成对 SVG/Canvas 飞轨共享同一贝塞尔控制点？
- [ ] **小技能也禁止"平移图标"**：必须有 出现（凝聚/萌发/绽开）→ 过程（弧线飞行逐帧粒子拖尾 / 描边生长 `stroke-dashoffset`）→ 命中（闪芯+冲击环+崩散）→ 消失（烟烬上浮 / 模糊下沉渐隐 / 碎片飘落）四段
