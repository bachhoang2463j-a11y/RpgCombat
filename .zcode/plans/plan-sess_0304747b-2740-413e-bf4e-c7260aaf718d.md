## 目标
为技能新增 `[他人]` 标签：技能含 `[他人]` 且含纯有益单体标签时，进入我方选目标（可对任意我方角色，**不排除自己**）。同时把"目标取向判定"从"只看第一个标签"改为"扫描全部三个标签"，消除顺序依赖。

## 核心模型
- `[他人]` 作为**独立布尔标记 `skill.isOthers`**（类似 `isReaction`/`kanpoTarget`），不占 type/type2/type3 标签槽位。
- 已在 subagent 复核：对现有结算(`applySingleTagEffect`)、属性计算(`getEffectiveStats`)、buff 渲染(`updateBuffUI`)、敌方AI(`selectEnemySkillAndTarget`) 全部零副作用。

## 两套触发逻辑（本方案核心）
1. **敌方单体选择**：扫描 type/type2/type3，含任一敌方单体伤害/妨害标签（`单体/穿透/眩晕/降/盲`）→ 进入敌方选目标（即使第一个标签是群攻）。结算时所有敌方标签作用于**选中的那个敌人**。
2. **`[他人]` 我方选择**：含 `[他人]` 且含任一纯有益单体标签 → 进入我方选目标（**不排除自己**，可对任意我方角色）。选中后所有纯有益单体标签作用于该队友。

**其余直接施放**：纯群技能（三个标签全部是群X）→ AOE 直接施放；纯单体有益且无 `[他人]` → 对自己施放（满足"只有带他人标签才能对其他角色"）；纯单体伤害 → 保持现状。

const skill = hero.skills[skillIndex];

- 用 `classifySkill` 结果替代逐标签 `isBeneficial`：

## 验证方式
- Node 提取 `<script>` 语法校验零报错
- 手操验证：
  - 无 `[他人]` 的纯单体有益技能 → 直接对自己施放
  - 有 `[他人]` 的纯单体有益技能 → 进入我方选目标，可对自己或任意队友
  - `[群攻][单增][单降]` → 进入敌方选目标（不再因群攻第一而直接 AOE）
  - `[单增][群攻]` → 进入敌方选目标（顺序无关）
  - 敌方 AI / 结算 / 渲染 无回归
