## 目标
强化防守者【强力反击】被动，使其触发几率随**仇恨值**动态提升；打出强力反击后，防守者仇恨回归"天生重装"档位（有效仇恨200），几率随之重置。

## 现状梳理（已确认）
- **仇恨构成**：有效仇恨 = `100 + baseTauntBonus + 临时tauntBuff`（`getEffectiveStats` L4708-4715）。
- **防守者天生200**：`onBattleInit` 设 `baseTauntBonus = 100`（L4056）。
- **现有仇恨增长源**（仅用现有机制，不加新来源）：
  - 常规反击成功 → `baseTauntBonus += 20`（L4921）。
  - `[嘲讽]` 技能 → 临时 `taunt` buff（L3978）。
- **强力反击被动**：`onDodge`（L4076-4102），当前固定 10% 几率，2×Atk，命中后 `updateHeroUI(target)` 刷新UI。
- **仇恨同时驱动**：盾牌精通命中率 `hit += taunt/10`（L4059）+ 索敌轮盘（L5086）。

## 设计决策（采用用户的选项）
1. **重置目标**：强力反击命中后，重置为防守者**天生200**（清除 `baseTauntBonus` 归0 + 清空 tauntBuff，然后 `onBattleInit` 口径下 baseTauntBonus=100 → 有效仇恨=200）。保留防守者吸引火力 + 命中加成的身份。
2. **仇恨来源**：仅用现有机制（`[嘲讽]` 技能 + 常规反击+20），不新增"受击涨仇恨"。
3. **几率公式**：`几率 = 10% + (有效仇恨 - 200) × 0.2%`，**不设上限**。

## 实现改动（仅改 `战斗前端-爬塔 V4.8.html`）

### 改动1：`onDodge` 几率改为动态计算（L4079-4080）
```js
const effectiveHate = getEffectiveStats(target).taunt;             // 当前有效仇恨
const powerCounterChance = 10 + Math.max(0, effectiveHate - 200) * 0.2; // 200以后每点+0.2%，无上限
if (Math.random() * 100 >= powerCounterChance) return;
```

### 改动2：强力反击命中后重置仇恨（在 L4101 `updateHeroUI(target)` 前插入）
```js
// 打出强力反击后，防守者仇恨回归"天生重装"档位（有效仇恨200），几率随之下一次反击重置
target.buffs = (target.buffs || []).filter(b => b.type !== 'taunt'); // 清除临时嘲讽buff
target.baseTauntBonus = 100;                                          // 回归防守者天生重装修正
createFloatingText(targetDom, '仇恨重置!', 'text-orange-300');
addHistory(`   ↳ 💢 ${target.name} 打出强力反击后气息收敛，仇恨回归 ${getEffectiveStats(target).taunt} 点！`);
```

### 改动3：UI 与刷新
`onDodge` 末尾已有 `updateHeroUI(target)`（L4101），其内部调用 `updateBuffUI` 会重新渲染仇恨徽章，故仇恨重置后徽章自动刷新，无需额外改动。

注：`baseTauntBonus = 100` 用于非隐匿者（`getEffectiveStats` 对非隐匿者下限钳制为 ≥1，防守者属非隐匿者），且不违反"隐匿者可为负"的特例。
