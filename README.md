# 战斗前端系统测试说明文档 (完整版)

**当前版本：V6.27**

本战斗前端采用**纯本地数值与逻辑运算**！所有的伤害计算、命中闪避、技能判定、敌方AI决策等都由前端代码瞬间完成，不需要等待 AI 思考。LLM（大语言模型）**只负责在战斗回合之间生成角色的对话（台词旁白）以及战后/撤退总结**，这极大地保证了战斗的流畅性与操作即时性。

---

## 1. 战局数据交互与 `<Combat_block>` 格式

当战斗开始或需要同步初始数据时，前端会通过正则检测酒馆聊天记录（SillyTavern 上下文）中是否包含 `<Combat_block>` 标签。

### AI 或系统提示词中需要包含的格式模板：
大模型（或系统预设角色卡）需要在文本中输出以下格式的 YAML 数据，注意必须用 `<Combat_block>` 和 `</Combat_block>` 包裹：

```html
<Combat_block>
战斗数据栏:
  我方列表(场地:有备而来):
    - 角色:
        名字: "烈阳剑尊"
        属性: "[HP:100/100][MP:50/50][Atk:15][Armor:5][Speed:110][职业:防守者]"
        技能:
          - "【赤阳剑气】[MP:10][单体;power:40][近战][特效:火焰01]"
          - "【烈阳守护】[MP:15][单防;power:20][持续:3]"
  敌方列表:
    - 角色:
        名字: "青眼苍狼"
        属性: "[HP:120/120][MP:30/30][Atk:12][Armor:3][Speed:95]"
        技能:
          - "【撕咬】[单体;power:25][近战]"
</Combat_block>
```

**解析规则说明：**
- **属性字段格式**：必须为 `[HP:当前/最大][MP:当前/最大][Atk:攻击力][Armor:护甲/防御][Speed:速度][职业:职业名]`；可选字段 `[行动次数:N]`（或 `[Act:N]`，如 `[行动次数:2]`）表示该角色每回合可行动 N 次，**我方与敌方通用**（V6.27），详见 §4.2。
- **技能字段格式**：必须为 `【技能名】[消耗类型:数值][标签;power:数值][伤害类型][特效:特效名]` 等组合。
- **场地字段（V6.14 可选）**：`我方列表` 行可带后缀 `(场地:场地名)`（如 `我方列表(场地:有备而来):`），冒号支持半角 `:` 与全角 `：`。带场地时战斗开始前会为我方全体注入对应场地效果；**不带场地标签则无任何场地效果**；未注册的场地名会被忽略并输出控制台警告（战斗正常建立）。场地效果**仅作用于我方**，敌方不受影响。详见 §3.8。
- **敌方名字 `*N` 数量后缀（V6.15）**：敌方名字末尾加 `*N`（如 `名字: "❄️《冰雪随从》*2"`）表示一次载入 N 个同名敌人，半角 `*` 与全角 `×` 均可，仅敌方列表生效（我方靠编辑器/持久化维护）。配合世界书图鉴可一次点名多个同类敌人，详见 §9。
- **敌方名字变种标签 `[...]`（V6.25）**：敌方名字后可直接跟一个或多个被 `[]` 包裹的变种标签（如 `名字: "食尸鬼*2[复活][智慧]"`），世界书模式下属性由图鉴词条提供、名字标签照样生效（LLM 只需输出敌人名字+变种标签即可）。**双写入点**：变种标签既可写在名字后，也可写在属性栏（如 `属性: "[HP:100/100][复活][智慧]"`），两处完全等价、任选其一。已支持 11 个标签见 §3.9：**`[复活]`**（死亡后 30% 血量复活一次，仅一次）、**`[智慧]`**（智慧旁白）、**`[流体]`/`[虚形]`/`[破法]`**（远程/近战/法术伤害 -50%）、**`[防火]`/`[耐毒]`/`[钢体]`**（免疫点燃/中毒/眩晕）、**`[再生]`**（每回合回血 10%）、**`[狂暴]`**（残血攻击 +50%）、**`[吸血]`**（攻击吸血 30%）。同一列表中「同名不同变种」敌人（如【食尸鬼】与【食尸鬼[复活]】）可安全共存。

## 2. 界面与 UI 系统介绍

### 2.1 对话界面与设置面板
- **“💬 对话”设置**：位于控制区，点击可配置 API 接口。
  - **API URL / Key / Model**：设置 LLM 接口，推荐使用能力强的模型（如 GPT-4o、Claude 3.5 Sonnet 或 Gemini 1.5 Pro）。
  - **传入酒馆聊天上下文**：开启后，系统在调用 LLM 时会抓取并附带 SillyTavern 的当前聊天历史，让角色的对话旁白能完美契合当前的故事线。
  - **上下文楼层数**：0 表示仅传入本次战局的日志，N 表示额外传入最近 N 层的聊天上下文。
  - **战局记录条数**：可在 `10` 到 `无限` 之间自由调节，决定发送给大模型进行判定的战斗历史记录条数。
- **“友方旁白 ON/OFF”**：开启后，当除 1 号位（玩家）之外的我方英雄行动时，会自动触发 LLM 生成该英雄此时的心理活动或口头禅气泡，极大增强角色扮演感。
- **“敌方旁白 ON/OFF”**：开启后，带 **`[智慧]`** 标签的敌方角色会在三个时机自动触发 LLM 旁白（V6.26）：
  - **回合开始**：该敌人行动回合开始时以本人口吻说一句当前战局台词（原有智慧旁白）；
  - **生命跌破 30%**：生命首次跌至 30% 以下时以本人口吻说一句绝境台词（如负隅顽抗、绝望嘶吼或放狠话），**每次跌破 30% 仅触发一次**（回血后再跌破不重复触发）；
  - **被击杀**：被击败时留下最后一句临死台词（**`[复活]`** 敌人第一次被击杀复活不触发、复活后再死正常触发）。
  - 同名敌人（如 `食尸鬼*2[智慧]`）各实例独立说话，气泡归属各自实体，不会串到第一个同名敌人头上。
- **对话输入框**：游戏开始后，底部会亮起对话栏，输入文字并发送，场上的友方角色会根据当前的战况和您的发言自动进行群聊气泡回应。

### 2.2 战斗面板 UI
- **时间轴 (Turn Queue)**：界面左侧竖向显示当前的行动顺序图标，排在最顶部的为当前行动者。
- **角色卡牌**：
  - **TP（潜能槽）**：受到伤害（被命中 +10）、施放技能（+5）、**成功闪避（+5）**、普攻与防御姿态时积攒。攒满 100 时会高亮闪烁，此时点击头像可激活“极限爆发”（双倍技能效果，技能施放时 TP 清零），再次点击可收敛。激活爆发时，消耗 TP 的技能会被自动禁用并显示 `⚠️ 爆发中禁 NTP`（避免因清零导致释放条件不足失败），点击头像切换爆发时技能面板会自动实时刷新。
  - **护盾条**：灰白色能量条覆盖在 HP 条上，优先吸收物理和法术伤害。
- **🛡️ 圣域帷幕与【肃正】全队共享屏障**：
  我方释放带有 `[肃正]` 标签的技能时，会为全队生成/累加笼罩小队的 3D 弧形金光圣域结界屏障（`teamBarrier`），在小队顶部独立显示进度条与数值。
  - **屏障名字跟随技能名**：屏障横幅/战报/飘字一律使用施放该屏障的技能名（如 `【魔法壁垒】[肃正;power:1000]` 施放后屏障即显示为"魔法壁垒"，而非固定的"圣域帷幕"）。
  - **`Armor:N` 屏障护甲**：语法 `[肃正;power:1000;Armor:40]`，屏障对所有伤害（**含穿透**）拥有 N 点护甲值，伤害进入屏障吸收前**先扣减屏障护甲**；屏障被击破后护甲随之消散重置。
  - **子类型属性克制**：语法 `[肃正:法术;power:1000;Armor:40]`（子类型取 `近战`/`远程`/`法术`，也可用独立 `[法术]`/`[近战]`/`[远程]` 标签代替），屏障对该属性伤害额外 **50% 减免**，减免发生在护甲扣除之前（先减半 → 再扣护甲 → 剩余量进屏障吸收）。
  - **显式覆盖叠加**：仅当施放技能携带 `Armor`/子类型参数时才更新屏障护甲/克制属性；裸 `[肃正]` 补盾只累加数值与刷新名字，不修改已有属性。
  - **伪实体肉盾**：屏障存在期间，敌方单体攻击强制归集命中屏障伪目标，我方英雄完全不被选中、不触发个人闪避判定。
  - **无视穿透与 Armor=0**：屏障自身无防具减伤（`Armor=0`）全额抵扣折算后的伤害，即使敌方带有 `[穿透]` 标签也无法绕过屏障打在英雄生命值上。
  - **群攻仅扣一次**：屏障作为单个实体，敌方群攻技能仅命中扣减 1 次屏障数值，溢出部分平铺泄漏给全体英雄。
  - **负面隔离与视觉演出**：屏障存在时全额隔离敌方非伤害 Debuff，跳过受击反应弹窗。受击时触发蜂窝能量网格过载高亮与强震屏，被打破时触发红闪碎裂效果。
- **战术撤退（V6.12）**：
  - **单独按钮化**：撤离已从右上角移入右侧行动面板，与 **⚔️ 普攻攻击 / ⚡ 释放技能 / 🛡️ 防御姿态** 并列为第四个按钮 **【💨 尝试撤离】**（仅在我方角色行动回合可用）。
  - **不再百分百成功**：点击后统计敌我双方**实时平均速度**（基础 `Speed` + 各自的 `[单速]/[群速]/[单缓]/[群缓]` 临时速度增益/减益，复用有效速度 `getEffectiveSpeed`），参照攻击闪避公式做一次对抗 roll：`Random(1~我方均速)` vs `Random(1~敌方均速)`，**我方结果更大才成功撤离**。
  - **失败**：写入战局文案（含双方均速与判定点数）并**消耗该行动角色的本回合**，不弹发送面板，战斗继续。
  - **成功**：弹出战后结算面板，完整汇总本场战局记录与小队当前伤势状态，生成"战术撤退小说文字模板"；点击"发送至酒馆输入框"将其注入酒馆对话，让 AI 接着撤退剧情继续扮演。
- **📜 战局记录预览（V6.12）**：右上角原【撤离】改为固定 **【记录】**，点击仅**只读展示**本次战局记录（`History Log`），不写撤离文案、不发送到酒馆。
- **⚠️ 动态属性修改提示**：
  在战斗进行期间，玩家可以**随时**点击“角色编辑”或“技能编辑”按钮，动态修改场上任何角色的当前 HP/MP、攻防、速度属性，或是调整技能伤害及消耗。修改保存后将**即时应用到当前战场中**，无需重开游戏，非常便于测试和即时调整平衡性。
- **⚙️ 防御恢复设置**：
  技能修改器最上方提供“战斗全局设置：防御/普攻恢复”区块，可自定义角色选择“防御”指令时恢复的 **MP 百分比**（默认 20%）与 **TP 百分比**（默认 25%，即原固定 +25 点），范围 0–100%；同时可自定义**普攻恢复 TP 点数**（默认 20 点，即原固定值）。所有设置会**持久化保存在浏览器（localStorage）**，刷新页面后自动恢复，方便测试人员灵活调整回气强度。
- **💾 我方角色技能持久化（聊天记录）**：
  在技能编辑器中点击“保存”后，我方角色的**配置与技能集**会持久化存储到酒馆助手的 **chat 变量**（即聊天记录 JSON 的 `chat_metadata.variables`），随聊天文件一起保存/导出。
  - **点保存即落盘**，修改/删除技能无需刷新。
  - **按角色名合并（持久化优先）**：同名角色的配置以持久化版本为准；同名技能以持久化版本覆盖；`<Combat_block>` 新增的技能会追加进战局，不会因持久化中不存在而丢弃。
  - **生命周期**：清空 `combatstatus`、刷新页面后，同名角色的技能依然存在；在酒馆中**新建聊天对话后技能消失**（新聊天文件无此数据）。
  - 仅持久化**我方角色**，敌方由 `<Combat_block>` 动态生成；依赖酒馆助手运行，无 localStorage 降级。

- **🎮 右侧行动与技能面板 UI**：
  - 右下角行动面板尺寸锁定为 **`260px` 宽度 × `172px` 高度**，与左侧英雄头像框顶底精准平齐对齐。
  - **初始行动面板**：提供高质感精致按钮（`⚔️ 普攻攻击` / `⚡ 释放技能` / `🛡️ 防御姿态`）。
  - **三排技能卡片**：【技能名称/类型】+【效果/蓄力/命中】+【消耗/限制/状态】分三排清晰展现，资源不足、用尽或处于极限爆发禁止 TP 技能状态时自动呈现暗沉灰色遮罩（`⚠️ MP不足` / `⚠️ 爆发中禁 NTP` / `🚫 已用尽`）。
  - **深蓝科技系蓄力菜单**：技能处于 `[延迟]` 蓄力中时，自动切换为深蓝渐变色风格的【继续蓄力 / 终止蓄力】交互面板。

## 3. 技能编辑器标签作用全解析


标签的配置格式一般为：`[标签名;power:数值]`（例如 `[单体;power:30]`）。如果省略 `;power:xx`，系统会默认赋予其基础数值。

### 3.1 伤害与攻击类标签
- `[单体]`：对单个敌方目标造成伤害。伤害计算公式：`技能实际威力 + (Buff攻击增益 * 爆发倍率)`。
- `[群攻]`：对敌方全体目标造成伤害。
- `[穿透]` / `[群穿透]`：造成的伤害将**无视目标的防御力(Armor)**，直接扣减生命值或护盾。
- `[眩晕]` / `[群眩晕]`：命中后对目标施加【眩晕】状态，使其**立即跳过下一次行动**。对多动单位（`Act > 1`）同样生效——其被眩晕后的下一次排轴行动（含额外行动）会被跳过，而非仅下回合开头。

> **💡 默认 Canvas 与 WebM 特效系统备注：**
> - **带括号的标签**：如 `[群攻(爆炸)]`、`[群攻(雷)]`、`[单体(枪击)]`、`[单体(火焰)]`、`[单体(光)]` 等依然可以使用。它们会触发对应样式的 Canvas 全屏粒子或默认刀光 SVG 动画。
> - **WebM 专属特效**：为了更加华丽的视觉演出，目前**更推荐使用 WebM 特效系统**。只需在技能中配置 `[特效:特效名]`（如 `[特效:火焰01]`），即可调用高清透明通道视频覆盖演出。

### 3.2 回护与增益类标签
- `[单回]` / `[群回]`：恢复生命值（HP）。圣职者或支援者使用时，溢出的治疗量会自动转化为护盾值。
- `[单回蓝]` / `[群回蓝]`：恢复法力值（MP）。
- `[单冲]` / `[群冲]`：恢复潜能值（TP）。`power` 数值即回复点数（如 `[单冲;power:30]` 恢复 30 点 TP），受 `[他人]` 目标选择修饰标签影响——`[单冲]` 带 `[他人]` 可对任意我方角色（含自己）施放，`[群冲]` 则对我方全体施放。
- `[单盾]` / `[群盾]`：为目标提供一层吸收对应数值伤害的护盾。
- `[肃正]` / `[肃正;power:数值]` / `[肃正:子类型;power:数值;Armor:N]`：**【全队共享伪实体肉盾屏障】** 为全队生成/累加共享圣域屏障（`teamBarrier`）。屏障存在期间拦截敌方单体索敌，强制归集命中屏障；全额抵挡 `[穿透]` 攻击；敌方群攻仅扣减 1 次屏障数值；全额隔离非伤害类 Debuff；屏障被击碎前我方英雄处于无敌保护状态。屏障名字跟随施放技能名；`Armor:N` 为屏障提供对所有伤害（含穿透）的固定护甲值；`:子类型`（近战/远程/法术，也可用独立 `[法术]` 等标签代替）使屏障对该属性伤害额外 50% 减免（先于护甲扣除）；屏障被击破后护甲/克制属性重置。
- `[单增]` / `[群增]`：提升目标攻击力（Atk），持续数回合（默认3回合）。
- `[单防]` / `[群防]`：提升目标防御力（Def），持续数回合（默认3回合）。
- `[单速]` / `[群速]`：**【速度增减（V6.11）】** 提升目标行动速度。速度增益为**独立的临时速度 buff**（`{type:'spd'}`），不改变角色基础属性 `Speed`、不影响闪避机制（基础闪避值仍取自原始速度），**只作用于行动顺序排轴**。`[单速]` 对我方单体施放（带 `[他人]` 可指定目标）、`[群速]` 对我方全体。施放瞬间**实时重排当前回合剩余队列**（更快者提前行动），且下一回合起由排轴自然生效；施法者已行动完，**不因加速额外获得一次行动**（除非技能带 `[再动]`）。
- `[单瞄]` / `[群瞄]`：提升目标命中率（Hit），持续数回合（默认3回合）。
- `[免伤]`：**【注意：这是单次消耗性的】** 为自身预存一次性减伤。在下一次遭受任何攻击时，按该数值临时提升防御进行抵挡，**无论是否成功抵挡，结算后立即被消耗清除**（与 `[回避]` 同属"单次消耗生效即消失"的机制）。
- `[他人]`：**【目标选择修饰标签】** 单独附加在技能上（类似 `[看破]`/`[反应]` 的独立标记，不占用技能类型槽位）。只有带 `[他人]` 的**纯有益单体技能**才能进入"我方选目标"，可对**任意我方角色（含自己）**施放；不带 `[他人]` 的纯单体有益技能（加攻/加防/加盾/治疗/回蓝/免伤/回避等）只能对自己施放。
- `[驱散:N]` / `[群驱散:N]`：**【负面状态驱散（我方专属）】** 对我方目标各驱散 N 个负面 buff（如 `【伊西斯之拥】[群回;power:100][群驱散:1]` 为全体回血 + 我方每人驱散 1 个负面）。`N` 可选，无数字默认 1（如 `[驱散]`、`[群驱散:3]`）。可驱散的目标负面状态：中毒、燃烧、眩晕，以及负面的降防/降准/降避/降攻；无负面时显示"无负面"占位反馈。`[驱散]` 视同 `[单增]` 类**纯增益单体**标签——不带 `[他人]` 只能对自己释放，带 `[他人]` 可对任意我方角色驱散；`[群驱散]` 则对我方全体释放。
- `[延迟:N]`：**【蓄力等待（我方专属）】** 技能先"蓄力"N 回合（该英雄处于 `⏳蓄力中`）。**资源（MP/HP/TP）在点击开启蓄力时即时校验扣除（押注资源）**；蓄力期间只处于准备态、不结算任何技能效果，但**仍可使用反应技能与看破**（不可主动普攻/技能/防御）。蓄力期间右侧技能面板切换为固定的两个选项：**【1.继续蓄力 2.终止蓄力】**；蓄力完成后面板变为 **【1.释放蓄力 2.终止蓄力】**，点击"释放蓄力"后若技能满足选目标条件（敌方单体/带 `[他人]` 的我方单体），则进入目标选择，否则直接释放。释放时不再重复扣除资源，并触发该技能全部效果（含自身携带的 `[加速:N]`）。
- `[加速:N]`：**【永久加速库存（我方专属）】** 一种不自动过期的加速点数。**只在蓄力释放结算完成时**才施加到角色身上；之后每次蓄力按"所需延迟回合"抵扣库存（蓄力3 遇 加速9 → 加速变6）。作为普通技能效果在施法时统一结算，可与其它标签（如 `[回避]`）同时触发；若技能带 `[他人]` 且所选目标为我方角色，则加速施加到该目标，否则施加到施法者自身。可为独立增益技能（直接+库存），也可与 `[延迟]` 同技能（如 `[延迟:3][加速:3]` 模拟"狙击枪3回合拼装后持续射击"：第一次蓄力3回合，完成后+3库存，**下一次**再使用即立即释放）。加速永远不影响"本次这一次"，只影响"之后"。
- `[限N次]`：**【本场战斗次数限制（我方专属）】** 限制某技能**本场战斗**内可使用的总次数（如 `[限1次]`、`[限3次]`）。累计用尽后：
  - **主动技能**：技能栏中该技能变为**灰色不可选中**，并显示 `[用尽]` 徽章；尚有余量时显示剩余次数 `[限N]`。
  - **反应/看破技能**（本就不显示在主动面板）：用尽后**后台静默失效**，不再出现在反应/看破弹窗候选；但弹窗中的技能按钮会**备注剩余次数**（如 `[限2次]`）。
  - 仅作用于**我方角色**，敌方 AI 技能选择不受此标签影响。
  - 次数为**本场战斗**内累计，战斗重置/新战局后自动恢复满值。

### 3.3 减益与控制类标签
- `[单降]` / `[群降]`：降低目标防御力（Def），持续数回合（默认3回合）。
- `[单盲]` / `[群盲]`：降准。降低目标命中率（Hit），持续数回合（默认3回合）。
- `[单缓]` / `[群缓]`：**【速度减速（V6.11）】** 降低目标行动速度。同 `[单速]/[群速]`，为**独立的临时速度 buff**，不改变基础 `Speed`、不影响闪避，只作用于行动顺序排轴；施放瞬间**实时重排当前回合剩余队列**（更慢者行动延后）。作为敌方减益随命中判定（有攻击标签时一次命中即施加全部妨害，纯减速时走完整闪避判定），接 `[必中]` 时强制命中。`[单缓]` 对敌方单体施放、`[群缓]` 对敌方全体。
- `[单滞]` / `[群滞]`：降避。降低目标闪避率（Eva），持续数回合（默认3回合）。
- `[单弱]` / `[群弱]`：降攻。降低目标攻击力（Atk），持续数回合（默认3回合）。
- `[中毒]` / `[群中毒]`：DoT伤害(毒)。每回合造成固定真实伤害，**叠层加深**，每次施放直接叠加新毒层，各层独立发作、互不覆盖，默认持续3回合。
- `[燃烧]` / `[群燃烧]`：DoT伤害(火)。每回合造成固定真实伤害，**灼烧禁疗**，重复施放不叠层、仅刷新强度与持续时间，且燃烧期间目标受到的 HP 治疗效果**减半**，默认持续3回合。

### 3.4 机动与机制类标签
- `[必中]`：**【命中强化修饰标签】** 独立标记，不占用技能类型槽位。带此标签的技能跳过命中/闪避判定，**伤害与敌方非伤害妨害效果恒命中**（大范围妨害拟真）。详细规则见 §5 第 4 点。
- `[嘲讽]`：调整自身的嘲讽值（仇恨权重）。数值为正时吸引火力，数值为负数时则为“隐匿”。
- `[再动]`：使目标立即获得额外的行动回合。带有再动标签的技能**每回合我方限制使用一次**。
- `[反击]` / `[群反击]`：使自身进入反击架势。当成功闪避近战伤害时，会自动使用基础攻击力 + 反击威力的力量回敬对手。
- `[回避]`：**【注意：这是单次消耗性的】** 提升自身闪避。在下一次遭遇任何敌方攻击判定时起效，**一旦判定完成（无论是否闪避成功），该 Buff 立刻被消耗清除**。
- `[单避]` / `[群避]`：**【注意：这是持续性的】** 提升自身闪避，该 Buff 会在指定的持续回合内一直生效，**期间遭受多次攻击也不会消失**。

### 3.5 伤害属性标签（辅助判断）
- `[近战]`、`[远程]`、`[法术]`：定义技能的伤害属性。例如，防守者的反击技能只能对 `[近战]` 伤害进行判定。
- **技能面板显示规则**：右下角技能选择面板**仅在技能带显式** `[近战]/[远程]/[法术]` 标签时才显示类型徽章；未显式标注类型的技能（编辑器类型下拉选「无(近战)」）在面板上不显示类型徽章，但**内部结算仍默认按近战处理**（作为敌方动态技能的兜底策略）。

### 3.6 看破战略中断标签
- `[看破:法术]`、`[看破:近战]`、`[看破:远程]`、`[看破:all]`：将该技能标记为看破技能，可在敌方宣告技能后、结算前尝试完全无效化对应伤害类型的技能。
- 看破技能也可以在技能编辑器中将“看破”下拉设为 `看破(全能)`、`看破(近战)`、`看破(远程)` 或 `看破(法术)`。
- **面板显示**：看破（`[看破]`）与反应（`[反应]`）类技能为**被动/打断触发机制**，不会出现在右下角主动技能选择面板中，仅当敌方宣告技能时由系统自动调用，无法被主动释放。

### 3.7 舍身护佑标签（V6.13）
- `[舍身]` / `[舍身:近战]` / `[舍身:远程]` / `[舍身:法术]`：将该技能标记为**舍身技能（我方专属）**，可在任意我方角色对敌方**单体**攻击闪避失败时，由其他角色挺身而出，替其承受本次攻击。
- **承接方式**：受击目标切换为舍身者，**跳过闪避（必中）**、伤害与附带减益**全盘接下**，后续减伤管线（屏障/防御/护盾/免伤/毅力留存/受击回气）对舍身者完整结算，原目标毫发无伤。
- **弹窗合并**：舍身候选与受击角色自身的**反应技能合并出现在同一弹窗**（无反应技能时单独弹出）；选择反应技仍可二次闪避"弹开"攻击；舍身者承接后**自身仍可释放反应技能**二次化解（但不可再连锁指定第三人舍身）。
- **优先级**：舍身在【看破】**之下**——看破在敌方技能宣告阶段（结算前）即拦截，成功则整个技能无效化；舍身需目标闪避失败后才触发。
- **限制**：仅对**单体**攻击生效（群攻不触发）；敌方不持有舍身技能；`[必中]` 不豁免舍身（必中仅跳过被动闪避，仍可被舍身/反应/看破主动化解）；屏障在场期间攻击被屏障归集、英雄不被选中，舍身天然不触发。
- **面板显示**：舍身（`[舍身]`）与看破/反应类技能同为**被动/打断触发机制**，不会出现在右下角主动技能选择面板中。

### 3.8 场地效果标签（V6.14）

**【场地】战前准备效果**：在 `<Combat_block>` 的 `我方列表` 行加后缀 `(场地:场地名)` 即可在战斗开始时为我方全体注入战前准备状态的 buff/debuff，合理反应跑团时战斗前的准备（如伏击、披甲、补给、地形等）。不带场地标签则无场地效果；场地效果**仅作用于我方**，敌方完全不受影响。

- **语法**：`我方列表(场地:有备而来):`（冒号支持半角 `:` 与全角 `：`）；未注册的场地名会被忽略并输出控制台警告（战斗正常建立）。
- **生效与衰减**：场地效果 = 战斗开始时给每个我方角色注入**真实 buff**（buff 图标正常显示在角色身上），衰减语义与全游戏「持续 N 回合」buff 一致——该角色**每回合首次行动**时消耗 1 次，**再动/多重施法/多动单位的额外行动不消耗场地回合**。
- **不可驱散**：场地 buff 带有 `fieldBuff` 标记，【驱散】技能**无法清除**（场地是战前环境状态，不是战斗中临时附加的 debuff）。
- **UI 展示**：右上角按钮区（【记录】按钮左侧）显示 🏟️ 场地徽章，鼠标悬浮可见效果描述；战斗开场战局日志写入 `🏟️ 场地：场地名 — 描述`。
- **重置保留**：场地效果在战斗开始时注入并随 `initialHeroesCache` 保存，**重置战斗后依然生效**（同一战局内反复重置均保留）。
- **【猝不及防】与反应技能**：场地闪避修正不影响反应技能——反应技的二次闪避判定只读取"本次反应新添加的回避值"，天然不受场地闪避增减影响。

### 3.9 敌方变种标签（V6.26）

**双写入点（通用）**：变种标签用 `[]` 包裹，可写在**名字**后（如 `名字: "食尸鬼[复活]"`），也可写在**属性栏**里（如 `属性: "[HP:100/100][复活]"`），**两处完全等价、任意混用**——解析端把两处的标签合并为同一命名空间，任一位置写入都生效，重复挂载幂等无害（布尔合并）。标签支持与 `*N` 数量后缀、世界书载入自由组合；从名字/属性栏中剥离后，`敌人.name` 与数值字段保持干净，标签不显示在战场上/战报/统计中。世界书模式下属性由图鉴词条提供、标签依然生效（写在 LLM 输出的名字上或词条属性栏里均可）。**未来新增任意标签均无需改解析代码**（属性栏与名字两处自动通吃）。

**全部标签均为敌方专属**（英雄无 tags 字段自动跳过）。已实现标签：

- **`[复活]`**：**【被动触发】** 带该标签的敌人**第一次**被击杀（HP 归 0）时，以 **30% 最大血量** 原地复活一次，随后正常回到战场与行动队列；仅一次（`reviveCount 1→0`），第二次被击杀即正常死亡。**覆盖所有死亡通道**：普攻/技能/群攻穿透/多段/反击/强力反击，以及毒/燃烧 DoT 在回合起始致死的场景——即使敌人在自己回合被反击杀死也会复活。
- **`[智慧]`**：与属性栏 `[智慧]` 完全等价，二者取并集（布尔合并，重复挂载幂等无害）。带 `[智慧]` 的敌方拥有**三档旁白触发点**（V6.26）：**回合开始**智慧旁白、**生命跌破 30%** 低血绝境台词（每次跌破仅触发一次）、**被击杀**临死台词；三者均受「敌方旁白」开关控制、均以本人口吻说话，详见 §2.1。详情弹窗名字旁显示智慧徽章。
- **`[流体]`** / **`[虚形]`** / **`[破法]`**：**【伤害类型减免】** 受到的**远程** / **近战** / **法术** 伤害各 **-50%**。作用于折算前原始伤害的独立减伤系数（与屏障克制同型），可与护甲/护盾/防御姿态叠加；【穿透】技能无视的是护甲、仍吃此属性减伤。*注：防守者【强力反击】为无类型上下文，不参与此减伤。*
- **`[防火]`** / **`[耐毒]`**：**【状态免疫】** 免疫**点燃** / **中毒** 施加（飘字「免疫·燃/免疫·毒」+ 战报）。
- **`[钢体]`**：**【状态免疫】** 免疫**眩晕**（飘字「免疫·眩晕」+ 战报）。
- **`[再生]`**：**【回合再生】** 每回合开始（TURN_START）回复 **最大 HP 10%**（上限不超过 maxHp）。
- **`[狂暴]`**：**【半血狂怒】** 当 **HP ≤ 30%** 时攻击力 **+50%**（肉鸽"半血狂怒"）。
- **`[吸血]`**：**【攻击吸血】** 对英雄造成**实际伤害**时，吸取其 **30%** 转化为自身回复（上限不超过 maxHp）。

> **示例**：`名字: "食尸鬼*2[复活][智慧]"` 或 `属性: "[HP:100/100][复活][智慧]"` → 载入 2 个「食尸鬼」，每个都带 [复活] 与 [智慧]，各可复活一次、各可触发智慧旁白。
> **组合示例**：`名字: "炎魔[防火][破法][再生][狂暴]"` → 免疫点燃、法术伤害减半、每回合回血 10%、残血时攻击暴涨。
> **同名不同变种共存**：`【食尸鬼】` 与 `【食尸鬼[复活]】` 在同一列表中是两个独立敌人，互不合并、不报错。

## 4. 独特的战斗机制

### 4.1 反应拦截机制 (Reaction)
反应机制是本系统最核心的博弈玩法，当角色遭受攻击时，可以通过消耗资源（MP/TP/HP）插队发动反制技能：
- **反应全能**：在技能编辑器中将反应类型设为 `[反应]` (或 `all`)。它可以应对**所有类型**的技能（无论是近战、远程还是法术伤害）。
  - *平衡建议*：由于全能反应能百分之百触发插队，属于极强机制，为了游戏平衡，**建议测试人员限制全能反应技能的数值强度，或大幅调高其 MP/TP 消耗**。
- **反应对应类型**：如 `[反应:近战]`、`[反应:远程]`、`[反应:法术]`。该反应技能只能在角色面临对应类型的伤害时才能激活。
- **执行逻辑**：
  在判定闪避失败、即将受伤前，系统会冻结时间轴。我方角色会弹出反应技能卡（敌方会自动智能选择）。如果角色选择使用反应技（例如使用了一个带有 `[回避]` 的身法反应），系统会在扣血前**临时增加回避值并重新进行二次闪避判定**，实现残血秀操作或完美格挡。
- **弹窗详情展示**：反应弹窗会同步展示敌方本次攻击的**技能名、伤害属性（近战/远程/法术）、攻击类型（单体/群攻）、技能威力与命中率**，方便玩家评估是否值得消耗资源插队反应。

### 4.2 多次行动与蓄力机制
- **多次行动 (Extra Actions)**：
  部分强力怪物或 Boss 在角色编辑里可以设置 `Act (行动次数) > 1`（例如每回合动 2-3 次）。
  为了防止高速连动怪完全霸占时间轴，系统在每回合排轴时，怪物的额外行动会进行**速度衰减**，公式为：`实际排轴速度 = 基础速度 - (当前行动序数 * 10)`。这给予了玩家插队换气的战术空间。
- **我方多动（V6.27）**：**我方角色同样支持多动**，与敌方共用同一套排轴/速度衰减/事件节流引擎。可在**角色编辑器**的「行动」框设置次数（或通过 YAML 属性栏 `[行动次数:N]`/`[Act:N]` 写入），值 >1 时该英雄每回合可行动 N 次；多动英雄行动时，行动面板顶部显示 `⏩ 剩余 N 次行动` 提示剩余行动次数。多动语义与敌方完全一致：蓄力推进 / DoT tick / 回合开始事件仅在**首次行动**触发、眩晕只吞当前一条行动、`[再动]`/祈愿插队不受影响。
- **蓄力大招机制 (Charge)**：
  如果怪物的技能配置了 `[Charge:数值]`（例如 `【灭世火雨】[Charge:3]`），则该技能平时处于封印状态，怪物每回合结束时会自动积攒 1 点充能。
  - 当充能攒满时，怪物的充能灯会全部点亮，并向玩家发出**蓄力大招警告**（Ultimate Warning）。
  - 在轮到怪物行动时，系统会锁死操作并播放华丽的**敌方大招特写过场动画 (Cut-in)**，随后倾泻毁灭性的技能效果，释放后大招充能归零重新积攒。

### 4.3 看破战略中断机制 (Kanpo)
看破是与反应系统不同的战略级反制机制：敌方宣告技能后、结算之前，系统会扫描我方持有匹配看破技能的角色，并弹出独立看破面板供玩家选择。
- **触发时机**：敌方技能宣告后、技能效果结算前。
- **匹配规则**：`看破(全能)` 可中断任意伤害类型；`看破(近战)`、`看破(远程)`、`看破(法术)` 只能匹配对应伤害类型。
- **效果**：使用看破后，敌方本次技能被完全无效化；敌方资源照常消耗，我方需支付技能自身的 MP/HP/TP 消耗。
- **弹窗详情展示**：看破弹窗会展示敌方技能的攻击类型（单体/群攻）、**威力与命中率**；若为**单体攻击**还会额外显示**攻击目标**（屏障拦截时显示屏障名字），让玩家能针对受击角色精准决策是否打断。

### 4.4 舍身护佑机制 (Sheshen)（V6.13）
舍身是与看破/反应不同的**守护向**反制机制：当某我方角色即将被敌方**单体**攻击命中（闪避失败）时，持有匹配【舍身】技能的其他角色可以挺身而出，替其承受本次攻击。
- **触发时机**：目标闪避失败后（晚于看破的宣告阶段，优先级在看破之下）。
- **执行逻辑**：舍身候选与受击角色自身的反应技能合并弹出；选择舍身后，受击目标切换为舍身者，**跳过闪避判定（必中）**，伤害与附带减益**全盘接下**，减伤管线（屏障/防御/护盾/免伤/毅力留存）对舍身者完整结算，原目标毫发无伤。
- **二次化解**：舍身者承接攻击后，**仍可触发自身反应技能**（如身法 `[回避]`）做二次闪避判定将攻击弹开；但不可再连锁指定第三人舍身（防无限转移）。
- **群攻无效**：群攻不触发舍身（v1 简化，需要时另行扩展）。

## 5. 命中与闪避判定公式

系统的判定完全遵循以下数学公式：
1. **角色初始闪避值 = 角色的敏捷值 (即属性中的“速度 Speed”)**。
2. **初次判定（面板对抗）**
   - 攻击方的最大命中上限 $Hit_{max}$ = `基础100 (或技能Hit修正) + 攻击方命中增益Buff`
   - 防守方的最大闪避上限 $Eva_{max}$ = `防守方基础速度 (Speed) + 防守方闪避增益Buff`
   - 双方各自进行随机 Roll 点：
     $$Roll_{Atk} = Random(1 \sim Hit_{max})$$
     $$Roll_{Def} = Random(1 \sim Eva_{max})$$
   - 判断条件：若 $Roll_{Def} > Roll_{Atk}$，则闪避成功（显示“闪避”）；若小于或等于，则进入即将受伤阶段（或触发上述的反应拦截判定）。
3. **减益也受命中判定影响（V6.8 起）**：作用于**敌方**的非伤害效果（降/盲/滞/弱/中毒/燃烧）不再无条件生效，而是跟随**该技能的攻击命中**——**一个技能有多少次伤害攻击就判定多少次，只要有一次攻击命中，其携带的所有敌方非伤害效果全部施加**。
   - 例：`【砷弹射击】[单体(枪击);power:80][单滞;power:20][中毒;power:20][Aim:180][远程]` 判定 1 次，1 次命中即施加全部效果。
   - 例：`【"清算"三连发】[单体(枪击);power:80][单体(枪击);power:80][单体(枪击);power:80][Aim:100]` 判定 3 次（3 次独立攻击）。
   - 例：`【温切斯特独头弹】[单体(枪击);power:100][单体(枪击);power:100][单降;power:10][Aim:150]` 判定 2 次（2 次攻击）；只要其中 1 次命中，单降即施加。
   - **纯减益技能**（无攻击标签、未带 `[必中]`）：整个技能仅做**一次**命中判定（对每个目标各 roll 一次），命中则该技能携带的全部敌方非伤害效果一次性施加、闪避则整体落空。该判定走**与伤害攻击完全相同的命中管线**——包含反应拦截、闪避飘字/烟雾等演出与判定公式，命中不足时可正常触发目标反应技能。
   - **我方增益**（回血/加攻/加防/加盾/再动/肃正/驱散等）保持无条件生效，不受命中判定影响。
4. **`[必中]` 标签**：技能带 `[必中]` 时**跳过被动命中/闪避判定**，伤害与妨害效果恒命中（与 `[护甲]` 等在技能中并列书写即可）。即便目标被动闪避成功（如无伤害则跳过判定），也会施加 debuff，拟真大范围妨害无法**被动**闪避规避。**但 `[必中]` 不豁免反应技能/看破等主动化解**——目标仍可弹反应面板或看破打断（V6.10 起）。例：`【极地暴风雪】[群攻;power:150][群降;power:30][Charge:4][Aim:120][MP:4][法术][必中]`、`【拉莱耶造雾术】[群盲;power:20][再动;power:1][Turns:10][MP:2][法术][限1次][必中]`。

> **✅ 已修复（V6.10）`[必中]` 不再跳过反应拦截**：敌方技能带 `[必中]` 时仍可触发我方角色反应技能（弹反应面板/看破打断）。`[必中]` 仅跳过**被动闪避 roll**，仍可被反应技/看破等**主动化解**。修复位置：`index.html` 反应拦截入口条件由 `!isDodged && !(skill && skill.guaranteedHit)` 改为 `!isDodged`。

## 6. 敌方 AI 索敌与决策机制

敌方攻击时的索敌目标遵循以下智能逻辑：
1. **优先保命与干扰**：如果自身 HP $\le$ 25%，优先对自己使用治疗或套盾；如果我方有英雄开启了“极限爆发”，优先对其使用降防/致盲等干扰技能。
2. **仇恨轮盘算法 (Taunt Roulette)**：
   当敌人使用单体伤害技能时，会扫描我方所有存活角色的“当前有效嘲讽值”（基础嘲讽值 + 嘲讽 Buff），并按嘲讽比例做成一个概率轮盘进行随机抽取。
   - **基础嘲讽值设定**：
     - **普通角色**：默认初始嘲讽值为 **100**。
     - **防守者**：因为天生防守被动，初始嘲讽值为 **200**（极其容易吸引火力）。
     - **隐匿者**：由于潜行被动，初始嘲讽值仅为 **50**（存在感极低）。
   - 这意味着防守者被怪物单体技能选中的概率是隐匿者的 **4倍**！

## 7. 七大职业与核心被动

职业在角色编辑界面的“职业”下拉框中选择，每个职业都拥有强力的专属被动：

1. **防守者**
   - **天生重装**：初始基础嘲讽值为 **200**。
   - **仇恨反击**：每次成功触发防守反击时，永久增加 20 点基础嘲讽值。
   - **盾牌精通**：将自身当前嘲讽值的 10% 转化为额外的命中率。
   - **【被动 - 强力反击】**：成功闪避攻击时有概率触发【强力反击】，以双倍攻击力（2 × Atk）重创目标（无视近战限制，不追加基础嘲讽），并伴有红色瞄准准心与全屏爆闪重击演出。触发几率随仇恨提升：基础 10%，每超出防守者天生仇恨（200）1 点 +0.2%（无上限）；打出一次强力反击后，仇恨回归天生 200 点，几率随之重置。**触发强力反击时不会同时触发普通反击**。
   - **【被动 - 毅力留存】**：每场战斗一次，承受致命伤害时强制保留 1 点 HP 避免死亡。
2. **狂战士**
   - **浴血奋战**：攻击力随损失的生命值比例线性提升（血越少攻击越高）。
   - **死斗**：当 HP 低于 30% 时，所有攻击附带【穿透】效果（无视防御），并额外造成自身已损失生命值 10% 的真实伤害。
   - **【被动 - 毅力留存】**：每场战斗一次，承受致命伤害时强制保留 1 点 HP 避免死亡（与防守者同款机制）。
3. **风行者**
   - **风之轻语**：面板闪避率（Eva）会额外增加当前的 TP（潜能）值。TP 越高，越难被击中。
   - **【被动 - 回避致命】**：每场战斗一次，遭受致命伤害时完美回避免除伤害（与隐匿者同款机制）。
4. **灾厄使 / 施毒者**
   - **痛打落水狗**：目标身上每有一个负面状态（中毒、燃烧、眩晕、降防、盲目等），对其造成的伤害提升 15%。
   - **淬毒攻击**：每次攻击附加 3 回合的【中毒】状态，中毒伤害受自身攻击力加成。
5. **隐匿者**
   - **绝对潜行**：初始基础嘲讽值为 **50**。可以通过技能将嘲讽值降得更低。
   - **狙击 / 暗杀**：使用远程技能时，隐匿深度（100 - 当前嘲讽值）越深，额外伤害越高；使用近战技能时，隐匿深度越深，越大概率直接【眩晕】目标。
   - **【隐匿值累积】**：隐匿者通过行动累积"隐匿值"（初始 50，即 100 - 初始嘲讽 50）：
     - **击杀敌人 +30**、**一回合内未被敌方攻击命中 +10**（每回合结束统一结算；被敌方攻击命中——无论是否扣血、是否被护盾/屏障格挡、是否-0——当回合均不累积，只有本回合根本没被攻击打到才算"未受击"）。
     - **临时负 `[嘲]` 技能**（如 `【无迹可寻】[嘲讽;power:-30]`）也计入隐匿值，按数值累加（+30），默认持续 3 回合后自然消失、隐匿值回落。
     - **隐匿值 ≥ 80**：立刻触发 1 次【再动】（每循环一次；若隐匿值跌回 80 以下则解锁，可再次触发）。
     - **隐匿值 ≥ 100**：立刻获得下一次非反应攻击 **攻击力 +50**（单次消耗【参考回避/免伤】，默认持续 3 回合，一旦**真正的攻击**命中后便消失），随后隐匿值**回归 50** 开启新一轮循环。
     - **急袭保留规则**：若隐匿值是在施放某个隐匿/buff 技能时跨 100、由该技能自身触发急袭的，则急袭 buff **不会**被该技能瞬间吞噬，而是保留给下一次真正的攻击（攻/单体/穿透/眩晕标签）使用。
   - **【被动 - 回避致命】**：每场战斗一次，遭受致命伤害时完美回避免除伤害。
6. **施法者**
   - **法能护罩**：战斗开始时，自动获得相当于**最大 MP 50%** 的护盾值。
   - **多重施法**：消耗 MP 释放技能时，有概率（根据耗蓝量决定，最高 30%）引发法力共鸣，立刻获得一个额外的行动回合（再动）。
7. **圣职者 / 支援者**
   - **神圣护盾**：治疗队友时，溢出的治疗量会自动转化为护盾。
   - **极限祈愿**：在满 TP 状态下点击其他队友，可以消耗全部 TP 发动祈愿，直接赋予该队友一次【再动】机会。

## 8. 如何自定义添加“角色头像”和“技能WebM特效”

### 8.1 自定义角色头像映射
在代码中搜索 `const AVATAR_MAP = {`，您会看到一个名字和链接的键值对。
- **添加方法**：在其中加入一行 `"角色名字": "图片URL地址"` 即可。
- *注：在角色编辑界面，您也可以直接在“头像”输入框中粘贴图片 URL。*

### 8.2 自定义 WebM 技能特效
在代码中搜索 `const WEBM_FX_REGISTRY = {`，注册您自己的透明通道 WebM 视频特效：
- **格式示例**：
  ```javascript
  '特效名称': { 
      url: 'WebM视频的URL链接', 
      scale: 1.4,              // 视频缩放比例
      particles: 'fire_aoe',   // 粒子背景类型
      audioUrl: '音效MP3链接'    // 该技能播放时专属的音效链接
  }
  ```
- 注册完成后，在技能编辑器中的 **“特效”** 下拉菜单中就会自动出现该特效名称，选中即可在施法时播放。

## 9. 世界书图鉴敌方数据载入系统（V6.15）

在 SillyTavern 酒馆环境中，可将**敌方图鉴世界书**（如 COC7 人类 NPC 战斗图鉴）作为敌方数据源：系统按敌方名字匹配世界书词条，从词条内嵌的 `<Combat_block>` 中精确载入该敌人的属性与技能。LLM 只需输出敌方名字，无需手写数值，避免摘录幻觉。

- **载入入口（准备页双按钮）**：准备页拆为 **【🧾 Yaml 载入】**（原逻辑，直接按 `<Combat_block>` 建局）与 **【📚 世界书载入】**（按名字匹配图鉴载入后建局）两个按钮；非酒馆助手环境自动隐藏世界书按钮，Yaml 载入流程完全不受影响。
- **世界书选择下拉（V6.16）**：世界书按钮下方带下拉框，可就地选择要载入的图鉴世界书（选中即绑定并持久化）。载入时**优先采用下拉选中值**；未选择时自动继承**角色卡绑定的世界书**（`getCharWorldbookNames('current')` 的 primary → additional[0]，兜底当前聊天文件绑定），绕开"绑定书里没怪物"的死锁；启动后自动绑定成功则后台预载词条，点击【世界书载入】即可直接使用。
- **匹配规则**：剥离名字 emoji 后按 ① 词条名精确 → ② 别名精确 → ③ 双向包含（≥2 字防误匹配）三级匹配（`resolveWorldbookEnemy`）。
- **载入行为**：
  - **命中**：提取词条内嵌 `<Combat_block>` 解析出敌人**属性/技能并完整替换**原数据（保留槽位 id），战局日志写入 `📚 图鉴载入：xxx → 条目「yyy」` 与命中统计。
  - **未命中**：保留 LLM 输出的原样数据（图鉴外临场新敌人不受影响）。
  - **全部未命中**：提示不开始战斗；读取失败/加载失败提示会**列出当前可用世界书清单**，便于核对名称与导入情况。
- **`*N` 数量后缀**：敌方名字加 `*N`（如 `❄️《冰雪随从》*2`）一次载入 N 个同名敌人（仅敌方列表生效，我方由编辑器/持久化维护）。
- **变种标签（V6.25）**：LLM 在敌人名字上加的 `[...]` 变种标签（如 `食尸鬼*2[复活][智慧]`）会在图鉴替换时**自动继承**——图鉴词条提供属性/技能，名字上的变种标签照样生效；标签也可直接写进图鉴词条的 `属性` 栏（双写入点等价）。当前支持 11 个标签见 §3.9。
- **右上角【📚 世界书管理】弹窗**：分区块管理——**① 绑定世界书**（可搜索名称单选列表 + 🔄 刷新 + 绑定信息）；**② 词条列表**（搜索框 + 启用开关 + 启用词条置顶 + 「查看」词条原文）；**③ 当前载入敌人**（当前 `enemiesData` 摘要）；**④ 词条数据预览**（只读查看词条 content）。
- **持久化**：绑定世界书名与各词条启用开关存入 `localStorage`（`rpg_combat_worldbook_settings`），刷新页面后保留；管理弹窗打开时未绑定会自动绑定并拉取词条。
