# 战斗前端系统测试说明文档 (完整版)

**当前版本：V5.8**

本战斗前端采用**纯本地数值与逻辑运算**！所有的伤害计算、命中闪避、技能判定、敌方AI决策等都由前端代码瞬间完成，不需要等待 AI 思考。LLM（大语言模型）**只负责在战斗回合之间生成角色的对话（台词旁白）以及战后/撤退总结**，这极大地保证了战斗的流畅性与操作即时性。

---

## 1. 战局数据交互与 `<Combat_block>` 格式

当战斗开始或需要同步初始数据时，前端会通过正则检测酒馆聊天记录（SillyTavern 上下文）中是否包含 `<Combat_block>` 标签。

### AI 或系统提示词中需要包含的格式模板：
大模型（或系统预设角色卡）需要在文本中输出以下格式的 YAML 数据，注意必须用 `<Combat_block>` 和 `</Combat_block>` 包裹：

```html
<Combat_block>
战斗数据栏:
  我方列表:
    - 角色:
        名字: "烈阳剑尊"
        属性: "[HP:100/100][MP:50/50][Atk:15][Armor:5][Speed:110][职业:防守者]"
        技能:
          - "【赤阳剑气】[MP:10][单体;power:40][近战][特效:火焰01]"
          - "【烈阳守护】[MP:15][单防;power:20][持续:3]"
  敌方列表:
    - 角色:
        名字: "青眼苍狼"
        属性: "[HP:120/120][MP:30/30][Atk:12][Armor:3][Speed:95]"
        技能:
          - "【撕咬】[单体;power:25][近战]"
</Combat_block>
```

**解析规则说明：**
- **属性字段格式**：必须为 `[HP:当前/最大][MP:当前/最大][Atk:攻击力][Armor:护甲/防御][Speed:速度][职业:职业名]`。
- **技能字段格式**：必须为 `【技能名】[消耗类型:数值][标签;power:数值][伤害类型][特效:特效名]` 等组合。

## 2. 界面与 UI 系统介绍

### 2.1 对话界面与设置面板
- **“💬 对话”设置**：位于控制区，点击可配置 API 接口。
  - **API URL / Key / Model**：设置 LLM 接口，推荐使用能力强的模型（如 GPT-4o、Claude 3.5 Sonnet 或 Gemini 1.5 Pro）。
  - **传入酒馆聊天上下文**：开启后，系统在调用 LLM 时会抓取并附带 SillyTavern 的当前聊天历史，让角色的对话旁白能完美契合当前的故事线。
  - **上下文楼层数**：0 表示仅传入本次战局的日志，N 表示额外传入最近 N 层的聊天上下文。
  - **战局记录条数**：可在 `10` 到 `无限` 之间自由调节，决定发送给大模型进行判定的战斗历史记录条数。
- **“友方旁白 ON/OFF”**：开启后，当除 1 号位（玩家）之外的我方英雄行动时，会自动触发 LLM 生成该英雄此时的心理活动或口头禅气泡，极大增强角色扮演感。
- **对话输入框**：游戏开始后，底部会亮起对话栏，输入文字并发送，场上的友方角色会根据当前的战况和您的发言自动进行群聊气泡回应。

### 2.2 战斗面板 UI
- **时间轴 (Turn Queue)**：界面顶部正中显示当前的行动顺序图标，排在最左侧的为当前行动者。
- **角色卡牌**：
  - **TP（潜能槽）**：受到伤害或行动时积攒。攒满 100 时会高亮闪烁，此时点击头像可激活“极限爆发”（双倍技能效果），再次点击可收敛。
  - **护盾条**：灰白色能量条覆盖在 HP 条上，优先吸收物理和法术伤害。
- **战术撤退按钮**：
  - 点击后，系统会判定小队主动脱离战斗，并立刻弹出**战后结算面板**。
  - 结算面板会完整汇总本场战斗的每一轮历史记录（History Log）以及小队成员当前的伤势状态，自动生成一段充满画面感和文学张力的“战术撤退小说文字模板”。
  - 点击“已填充至输入框”按钮，可以直接将这段渲染文本注入到酒馆对话框中，让 AI 接着这段撤退剧情继续扮演。
- **⚠️ 动态属性修改提示**：
  在战斗进行期间，玩家可以**随时**点击“角色编辑”或“技能编辑”按钮，动态修改场上任何角色的当前 HP/MP、攻防、速度属性，或是调整技能伤害及消耗。修改保存后将**即时应用到当前战场中**，无需重开游戏，非常便于测试和即时调整平衡性。
- **⚙️ 防御恢复设置**：
  技能修改器最上方提供“战斗全局设置：防御/普攻恢复”区块，可自定义角色选择“防御”指令时恢复的 **MP 百分比**（默认 20%）与 **TP 百分比**（默认 25%，即原固定 +25 点），范围 0–100%；同时可自定义**普攻恢复 TP 点数**（默认 20 点，即原固定值）。所有设置会**持久化保存在浏览器（localStorage）**，刷新页面后自动恢复，方便测试人员灵活调整回气强度。
- **💾 我方角色技能持久化（聊天记录）**：
  在技能编辑器中点击“保存”后，我方角色的**配置与技能集**会持久化存储到酒馆助手的 **chat 变量**（即聊天记录 JSON 的 `chat_metadata.variables`），随聊天文件一起保存/导出。
  - **点保存即落盘**，修改/删除技能无需刷新。
  - **按角色名合并（持久化优先）**：同名角色的配置以持久化版本为准；同名技能以持久化版本覆盖；`<Combat_block>` 新增的技能会追加进战局，不会因持久化中不存在而丢弃。
  - **生命周期**：清空 `combatstatus`、刷新页面后，同名角色的技能依然存在；在酒馆中**新建聊天对话后技能消失**（新聊天文件无此数据）。
  - 仅持久化**我方角色**，敌方由 `<Combat_block>` 动态生成；依赖酒馆助手运行，无 localStorage 降级。

- **🎮 右侧行动与技能面板 UI**：
  - 右下角行动面板尺寸锁定为 **`260px` 宽度 × `172px` 高度**，与左侧英雄头像框顶底精准平齐对齐。
  - **初始行动面板**：提供高质感精致按钮（`⚔️ 普攻攻击` / `⚡ 释放技能` / `🛡️ 防御姿态`）。
  - **三排技能卡片**：【技能名称/类型】+【效果/蓄力/命中】+【消耗/限制/状态】分三排清晰展现，资源不足或用尽自动呈现暗沉灰色遮罩（`⚠️ MP不足` / `🚫 已用尽`）。
  - **深蓝科技系蓄力菜单**：技能处于 `[延迟]` 蓄力中时，自动切换为深蓝渐变色风格的【继续蓄力 / 终止蓄力】交互面板。

## 3. 技能编辑器标签作用全解析


标签的配置格式一般为：`[标签名;power:数值]`（例如 `[单体;power:30]`）。如果省略 `;power:xx`，系统会默认赋予其基础数值。

### 3.1 伤害与攻击类标签
- `[单体]`：对单个敌方目标造成伤害。伤害计算公式：`技能实际威力 + (Buff攻击增益 * 爆发倍率)`。
- `[群攻]`：对敌方全体目标造成伤害。
- `[穿透]` / `[群穿透]`：造成的伤害将**无视目标的防御力(Armor)**，直接扣减生命值或护盾。
- `[眩晕]` / `[群眩晕]`：命中后对目标施加【眩晕】状态，使其**立即跳过下一次行动**。对多动单位（`Act > 1`）同样生效——其被眩晕后的下一次排轴行动（含额外行动）会被跳过，而非仅下回合开头。

> **💡 默认 Canvas 与 WebM 特效系统备注：**
> - **带括号的标签**：如 `[群攻(爆炸)]`、`[群攻(雷)]`、`[单体(枪击)]`、`[单体(火焰)]`、`[单体(光)]` 等依然可以使用。它们会触发对应样式的 Canvas 全屏粒子或默认刀光 SVG 动画。
> - **WebM 专属特效**：为了更加华丽的视觉演出，目前**更推荐使用 WebM 特效系统**。只需在技能中配置 `[特效:特效名]`（如 `[特效:火焰01]`），即可调用高清透明通道视频覆盖演出。

### 3.2 回护与增益类标签
- `[单回]` / `[群回]`：恢复生命值（HP）。圣职者或支援者使用时，溢出的治疗量会自动转化为护盾值。
- `[单回蓝]` / `[群回蓝]`：恢复法力值（MP）。
- `[单盾]` / `[群盾]`：为目标提供一层吸收对应数值伤害的护盾。
- `[单增]` / `[群增]`：提升目标攻击力（Atk），持续数回合（默认3回合）。
- `[单防]` / `[群防]`：提升目标防御力（Def），持续数回合（默认3回合）。
- `[单瞄]` / `[群瞄]`：提升目标命中率（Hit），持续数回合（默认3回合）。
- `[免伤]`：**【注意：这是单次消耗性的】** 为自身预存一次性减伤。在下一次遭受任何攻击时，按该数值临时提升防御进行抵挡，**无论是否成功抵挡，结算后立即被消耗清除**（与 `[回避]` 同属"单次消耗生效即消失"的机制）。
- `[他人]`：**【目标选择修饰标签】** 单独附加在技能上（类似 `[看破]`/`[反应]` 的独立标记，不占用技能类型槽位）。只有带 `[他人]` 的**纯有益单体技能**才能进入"我方选目标"，可对**任意我方角色（含自己）**施放；不带 `[他人]` 的纯单体有益技能（加攻/加防/加盾/治疗/回蓝/免伤/回避等）只能对自己施放。
- `[驱散:N]` / `[群驱散:N]`：**【负面状态驱散（我方专属）】** 对我方目标各驱散 N 个负面 buff（如 `【伊西斯之拥】[群回;power:100][群驱散:1]` 为全体回血 + 我方每人驱散 1 个负面）。`N` 可选，无数字默认 1（如 `[驱散]`、`[群驱散:3]`）。可驱散的目标负面状态：中毒、眩晕，以及负面的降防/降准/降避/降攻；无负面时显示"无负面"占位反馈。`[驱散]` 视同 `[单增]` 类**纯增益单体**标签——不带 `[他人]` 只能对自己释放，带 `[他人]` 可对任意我方角色驱散；`[群驱散]` 则对我方全体释放。
- `[延迟:N]`：**【蓄力等待（我方专属）】** 技能先"蓄力"N 回合（该英雄处于 `⏳蓄力中`），**蓄力期间只处于准备态、不结算任何技能效果**，但**仍可使用反应技能与看破**（不可主动普攻/技能/防御）。蓄力期间右侧技能面板切换为固定的两个选项：**【1.继续蓄力 2.终止蓄力】**；蓄力完成后面板变为 **【1.释放蓄力 2.终止蓄力】**，点击"释放蓄力"后若技能满足选目标条件（敌方单体/带 `[他人]` 的我方单体），则进入目标选择，否则直接释放。释放时才触发该技能全部效果（含自身携带的 `[加速:N]`）。
- `[加速:N]`：**【永久加速库存（我方专属）】** 一种不自动过期的加速点数。**只在蓄力释放结算完成时**才施加到角色身上；之后每次蓄力按"所需延迟回合"抵扣库存（蓄力3 遇 加速9 → 加速变6）。作为普通技能效果在施法时统一结算，可与其它标签（如 `[回避]`）同时触发；若技能带 `[他人]` 且所选目标为我方角色，则加速施加到该目标，否则施加到施法者自身。可为独立增益技能（直接+库存），也可与 `[延迟]` 同技能（如 `[延迟:3][加速:3]` 模拟"狙击枪3回合拼装后持续射击"：第一次蓄力3回合，完成后+3库存，**下一次**再使用即立即释放）。加速永远不影响"本次这一次"，只影响"之后"。
- `[限N次]`：**【本场战斗次数限制（我方专属）】** 限制某技能**本场战斗**内可使用的总次数（如 `[限1次]`、`[限3次]`）。累计用尽后：
  - **主动技能**：技能栏中该技能变为**灰色不可选中**，并显示 `[用尽]` 徽章；尚有余量时显示剩余次数 `[限N]`。
  - **反应/看破技能**（本就不显示在主动面板）：用尽后**后台静默失效**，不再出现在反应/看破弹窗候选；但弹窗中的技能按钮会**备注剩余次数**（如 `[限2次]`）。
  - 仅作用于**我方角色**，敌方 AI 技能选择不受此标签影响。
  - 次数为**本场战斗**内累计，战斗重置/新战局后自动恢复满值。

### 3.3 减益与控制类标签
- `[单降]` / `[群降]`：降低目标防御力（Def），持续数回合（默认3回合）。
- `[单盲]` / `[群盲]`：降准。降低目标命中率（Hit），持续数回合（默认3回合）。

### 3.4 机动与机制类标签
- `[嘲讽]`：调整自身的嘲讽值（仇恨权重）。数值为正时吸引火力，数值为负数时则为“隐匿”。
- `[再动]`：使目标立即获得额外的行动回合。带有再动标签的技能**每回合我方限制使用一次**。
- `[反击]` / `[群反击]`：使自身进入反击架势。当成功闪避近战伤害时，会自动使用基础攻击力 + 反击威力的力量回敬对手。
- `[回避]`：**【注意：这是单次消耗性的】** 提升自身闪避。在下一次遭遇任何敌方攻击判定时起效，**一旦判定完成（无论是否闪避成功），该 Buff 立刻被消耗清除**。
- `[单避]` / `[群避]`：**【注意：这是持续性的】** 提升自身闪避，该 Buff 会在指定的持续回合内一直生效，**期间遭受多次攻击也不会消失**。

### 3.5 伤害属性标签（辅助判断）
- `[近战]`、`[远程]`、`[法术]`：定义技能的伤害属性。例如，防守者的反击技能只能对 `[近战]` 伤害进行判定。
- **技能面板显示规则**：右下角技能选择面板**仅在技能带显式** `[近战]/[远程]/[法术]` 标签时才显示类型徽章；未显式标注类型的技能（编辑器类型下拉选「无(近战)」）在面板上不显示类型徽章，但**内部结算仍默认按近战处理**（作为敌方动态技能的兜底策略）。

### 3.6 看破战略中断标签
- `[看破:法术]`、`[看破:近战]`、`[看破:远程]`、`[看破:all]`：将该技能标记为看破技能，可在敌方宣告技能后、结算前尝试完全无效化对应伤害类型的技能。
- 看破技能也可以在技能编辑器中将“看破”下拉设为 `看破(全能)`、`看破(近战)`、`看破(远程)` 或 `看破(法术)`。
- **面板显示**：看破（`[看破]`）与反应（`[反应]`）类技能为**被动/打断触发机制**，不会出现在右下角主动技能选择面板中，仅当敌方宣告技能时由系统自动调用，无法被主动释放。

## 4. 独特的战斗机制

### 4.1 反应拦截机制 (Reaction)
反应机制是本系统最核心的博弈玩法，当角色遭受攻击时，可以通过消耗资源（MP/TP/HP）插队发动反制技能：
- **反应全能**：在技能编辑器中将反应类型设为 `[反应]` (或 `all`)。它可以应对**所有类型**的技能（无论是近战、远程还是法术伤害）。
  - *平衡建议*：由于全能反应能百分之百触发插队，属于极强机制，为了游戏平衡，**建议测试人员限制全能反应技能的数值强度，或大幅调高其 MP/TP 消耗**。
- **反应对应类型**：如 `[反应:近战]`、`[反应:远程]`、`[反应:法术]`。该反应技能只能在角色面临对应类型的伤害时才能激活。
- **执行逻辑**：
  在判定闪避失败、即将受伤前，系统会冻结时间轴。我方角色会弹出反应技能卡（敌方会自动智能选择）。如果角色选择使用反应技（例如使用了一个带有 `[回避]` 的身法反应），系统会在扣血前**临时增加回避值并重新进行二次闪避判定**，实现残血秀操作或完美格挡。

### 4.2 敌人的多次行动与蓄力机制
- **多次行动 (Extra Actions)**：
  部分强力怪物或 Boss 在角色编辑里可以设置 `Act (行动次数) > 1`（例如每回合动 2-3 次）。
  为了防止高速连动怪完全霸占时间轴，系统在每回合排轴时，怪物的额外行动会进行**速度衰减**，公式为：`实际排轴速度 = 基础速度 - (当前行动序数 * 10)`。这给予了玩家插队换气的战术空间。
- **蓄力大招机制 (Charge)**：
  如果怪物的技能配置了 `[Charge:数值]`（例如 `【灭世火雨】[Charge:3]`），则该技能平时处于封印状态，怪物每回合结束时会自动积攒 1 点充能。
  - 当充能攒满时，怪物的充能灯会全部点亮，并向玩家发出**蓄力大招警告**（Ultimate Warning）。
  - 在轮到怪物行动时，系统会锁死操作并播放华丽的**敌方大招特写过场动画 (Cut-in)**，随后倾泻毁灭性的技能效果，释放后大招充能归零重新积攒。

### 4.3 看破战略中断机制 (Kanpo)
看破是与反应系统不同的战略级反制机制：敌方宣告技能后、结算之前，系统会扫描我方持有匹配看破技能的角色，并弹出独立看破面板供玩家选择。
- **触发时机**：敌方技能宣告后、技能效果结算前。
- **匹配规则**：`看破(全能)` 可中断任意伤害类型；`看破(近战)`、`看破(远程)`、`看破(法术)` 只能匹配对应伤害类型。
- **效果**：使用看破后，敌方本次技能被完全无效化；敌方资源照常消耗，我方需支付技能自身的 MP/HP/TP 消耗。

## 5. 命中与闪避判定公式

系统的判定完全遵循以下数学公式：
1. **角色初始闪避值 = 角色的敏捷值 (即属性中的“速度 Speed”)**。
2. **初次判定（面板对抗）**
   - 攻击方的最大命中上限 $Hit_{max}$ = `基础100 (或技能Hit修正) + 攻击方命中增益Buff`
   - 防守方的最大闪避上限 $Eva_{max}$ = `防守方基础速度 (Speed) + 防守方闪避增益Buff`
   - 双方各自进行随机 Roll 点：
     $$Roll_{Atk} = Random(1 \sim Hit_{max})$$
     $$Roll_{Def} = Random(1 \sim Eva_{max})$$
   - 判断条件：若 $Roll_{Def} > Roll_{Atk}$，则闪避成功（显示“闪避”）；若小于或等于，则进入即将受伤阶段（或触发上述的反应拦截判定）。

## 6. 敌方 AI 索敌与决策机制

敌方攻击时的索敌目标遵循以下智能逻辑：
1. **优先保命与干扰**：如果自身 HP $\le$ 25%，优先对自己使用治疗或套盾；如果我方有英雄开启了“极限爆发”，优先对其使用降防/致盲等干扰技能。
2. **仇恨轮盘算法 (Taunt Roulette)**：
   当敌人使用单体伤害技能时，会扫描我方所有存活角色的“当前有效嘲讽值”（基础嘲讽值 + 嘲讽 Buff），并按嘲讽比例做成一个概率轮盘进行随机抽取。
   - **基础嘲讽值设定**：
     - **普通角色**：默认初始嘲讽值为 **100**。
     - **防守者**：因为天生防守被动，初始嘲讽值为 **200**（极其容易吸引火力）。
     - **隐匿者**：由于潜行被动，初始嘲讽值仅为 **50**（存在感极低）。
   - 这意味着防守者被怪物单体技能选中的概率是隐匿者的 **4倍**！

## 7. 七大职业与核心被动

职业在角色编辑界面的“职业”下拉框中选择，每个职业都拥有强力的专属被动：

1. **防守者**
   - **天生重装**：初始基础嘲讽值为 **200**。
   - **仇恨反击**：每次成功触发防守反击时，永久增加 20 点基础嘲讽值。
   - **盾牌精通**：将自身当前嘲讽值的 10% 转化为额外的命中率。
   - **【被动 - 强力反击】**：成功闪避攻击时有概率触发【强力反击】，以双倍攻击力（2 × Atk）重创目标（无视近战限制，不追加基础嘲讽），并伴有红色瞄准准心与全屏爆闪重击演出。触发几率随仇恨提升：基础 10%，每超出防守者天生仇恨（200）1 点 +0.2%（无上限）；打出一次强力反击后，仇恨回归天生 200 点，几率随之重置。
   - **【被动 - 毅力留存】**：每场战斗一次，承受致命伤害时强制保留 1 点 HP 避免死亡。
2. **狂战士**
   - **浴血奋战**：攻击力随损失的生命值比例线性提升（血越少攻击越高）。
   - **死斗**：当 HP 低于 30% 时，所有攻击附带【穿透】效果（无视防御），并额外造成自身已损失生命值 10% 的真实伤害。
3. **风行者**
   - **风之轻语**：面板闪避率（Eva）会额外增加当前的 TP（潜能）值。TP 越高，越难被击中。
4. **灾厄使 / 施毒者**
   - **痛打落水狗**：目标身上每有一个负面状态（中毒、眩晕、降防、盲目等），对其造成的伤害提升 15%。
   - **淬毒攻击**：每次攻击附加 3 回合的【中毒】状态，中毒伤害受自身攻击力加成。
5. **隐匿者**
   - **绝对潜行**：初始基础嘲讽值为 **50**。可以通过技能将嘲讽值降得更低。
   - **狙击 / 暗杀**：使用远程技能时，隐匿深度（100 - 当前嘲讽值）越深，额外伤害越高；使用近战技能时，隐匿深度越深，越大概率直接【眩晕】目标。
   - **【隐匿值累积】**：隐匿者通过行动累积"隐匿值"（初始 50，即 100 - 初始嘲讽 50）：
     - **击杀敌人 +30**、**成功闪避 +4**（固化为永久隐匿深度降低嘲讽）。
     - **临时负 `[嘲]` 技能**（如 `【无迹可寻】[嘲讽;power:-30]`）也计入隐匿值，按数值累加（+30），默认持续 3 回合后自然消失、隐匿值回落。
     - **隐匿值 ≥ 80**：立刻触发 1 次【再动】（每循环一次；若隐匿值跌回 80 以下则解锁，可再次触发）。
     - **隐匿值 ≥ 100**：立刻获得下一次非反应攻击 **攻击力 +80**（单次消耗【参考回避/免伤】，默认持续 3 回合，一旦**真正的攻击**命中后便消失），随后隐匿值**回归 50** 开启新一轮循环。
     - **急袭保留规则**：若隐匿值是在施放某个隐匿/buff 技能时跨 100、由该技能自身触发急袭的，则急袭 buff **不会**被该技能瞬间吞噬，而是保留给下一次真正的攻击（攻/单体/穿透/眩晕标签）使用。
   - **【被动 - 回避致命】**：每场战斗一次，遭受致命伤害时完美回避免除伤害。
6. **施法者**
   - **法能护罩**：战斗开始时，自动获得相当于**最大 MP 50%** 的护盾值。
   - **多重施法**：消耗 MP 释放技能时，有概率（根据耗蓝量决定，最高 30%）引发法力共鸣，立刻获得一个额外的行动回合（再动）。
7. **圣职者 / 支援者**
   - **神圣护盾**：治疗队友时，溢出的治疗量会自动转化为护盾。
   - **极限祈愿**：在满 TP 状态下点击其他队友，可以消耗全部 TP 发动祈愿，直接赋予该队友一次【再动】机会。

## 8. 如何自定义添加“角色头像”和“技能WebM特效”

### 8.1 自定义角色头像映射
在代码中搜索 `const AVATAR_MAP = {`，您会看到一个名字和链接的键值对。
- **添加方法**：在其中加入一行 `"角色名字": "图片URL地址"` 即可。
- *注：在角色编辑界面，您也可以直接在“头像”输入框中粘贴图片 URL。*

### 8.2 自定义 WebM 技能特效
在代码中搜索 `const WEBM_FX_REGISTRY = {`，注册您自己的透明通道 WebM 视频特效：
- **格式示例**：
  ```javascript
  '特效名称': { 
      url: 'WebM视频的URL链接', 
      scale: 1.4,              // 视频缩放比例
      particles: 'fire_aoe',   // 粒子背景类型
      audioUrl: '音效MP3链接'    // 该技能播放时专属的音效链接
  }
  ```
- 注册完成后，在技能编辑器中的 **“特效”** 下拉菜单中就会自动出现该特效名称，选中即可在施法时播放。
