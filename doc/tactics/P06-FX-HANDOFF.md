# P06 前端效果交接

## 接口边界

特效层只消费 `battle.attack()` 的提交结果，不再自行查询命中、选目标、扣费或掷骰。稳定 payload 为：

- `result.casterId`、`result.skill`、`result.aim`、`result.facing`：动作身份、瞄准与演出方向。
- `result.query.shape`、`cells`、`collisionPoint`、`contact`、`blastCenter`：作用区、空间碰撞/爆心。坐标均为世界米格；地图像素由 view 层按 `Q=50` 映射。
- `result.query.actualTargetIds` / `targets`：规则真值，包含完整单位占格；仅命中中心落入空间区域的单位，单位按 ID 去重。
- `result.query.disclosureTargetIds`：可在预览向玩家披露的目标；不得据此改写真实命中集合。P08 感知来源尚未实现，当前由 `visibleUnitIds` 输入快照模拟。
- `result.query.slotTargets` / `damageTargetIds`：按槽次序输出 `{index,tag,side,scope,attack,targetIds}`；P06 只执行可识别的攻击伤害槽，治疗、状态、增益、召唤等只提供空间候选，不结算其效果。
- `result.hits[]`：逐目标最终结果 `{targetId,hit,damage...,hpBefore,hpAfter,down,logIndex,logEnd}`。受击/闪避揭示由导演在接触拍点调用 `playHitFeedback`；动作/逐目标音频 wave 以同一 action 结果为键，不能重播规则结算。

预览与执行都由 `queryAttack()` 构造几何结果；确认执行后 `attack()` 消费一次该结果并逐目标调用伤害结算。取消预览不扣资源。闪避只影响已锁定目标，不转火后方；命中判定不由动画 callback 驱动。

## 空间形状

- 单体：锁定目标中心；普通投射会被前方单位或实墙阻挡。治疗等非攻击单体槽不被角色截走，但仍检查施法者射程和墙体。
- 直线：显式空间范围决定沿线多目标；友方不挡且不受伤，实墙裁掉墙后作用格；`[穿透]` 是破防语义，不意味着穿单位或墙。
- 扇形、圆形：用查询返回的 `cells` 绘制，不从预览图形反推目标；普通墙/遮挡裁切作用区。
- 全域：遍历全地图单位，不受普通墙/视距过滤；P10 结界规则另行实现。
- 爆炸：`contact` 为首个单位/墙接触，`collisionPoint` 与 `shape.center` 为爆心；无接触时爆心为用户选定终点。接触单位占格从 AoE 受击格剔除，不额外承受一次接触命中，也不先掷接触闪避。
