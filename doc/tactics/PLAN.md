# 战棋开发路线：主题恒定房间拼接，开局即战

## 核心目的

让棋盘直接承接酒馆中已经开战的剧情。新战斗不需要探索地图、索敌或唤醒敌群；先把一场可复现、可交互、可结算的战斗做好，再加能通过走位应对的战术压力。

## 具体任务

2026-11-27 已确认下列顺序，第 1 阶段的固定三层礼拜堂 Demo 基线、阶段 2—4 的基础战斗主线已交付；主题房间库与拼接仍待制作，不把 Demo 完成等同于完整规格或正式酒馆发布完成。[SPEC.md](SPEC.md) 是规则依据，[STATUS.md](STATUS.md) 记录当前实现。旧 P00—P12 路线及原工时估算归档为[历史计划](obsolete_documents/PLAN.md)，不作为后续施工清单。P01/P03 等仍有效的协议与时钟契约继续使用，不重建底座。

## 1. 开局即战与地图基线（固定三层 Demo 已交付，主题拼接待做）

- 初版去掉随机地图，也不再局限单房间。每个主题提供若干恒定房间：尺寸、墙体、门位与内部陈设全部手工固定；每局只改变房间的拼接顺序与连接方向。
- Demo 开发期以现有三层礼拜堂为权威测试与首个主题房间库；每主题的房间清单与连接口在实施前逐主题送审，不擅自编造。基础玩法完工后再扩充其他主题。
- 当前 Demo 使用固定三层礼拜堂和显式站位，重试恢复同一场地、站位和资源，不重新生成地形。后续主题拼接须保证全部房间连通并留出连续的 2×2 通路；种子仅决定拼接，不能改变房间内部固定陈设。
- 移除室内随机布墙、场景迷雾、常规发现停步及旧接战警戒；不实施听力、巡逻索敌或通用线索记忆。开局双方单位位置已知；保留高墙对攻击的空间限制，以及技能生成浓雾的遮蔽、致盲与出雾行为。
- 迁移典型礼拜堂主验收局：保留 4 英雄、6 敌、2 召唤模板、技能和礼拜堂主题；默认 Demo 使用固定三层地图与原样本显式站位，主题拼接完成后再切换，共用原 YAML 的阵容和技能，不迁走工作台与历史测试仍读取的原样本。
- **Demo 退出条件（已交付）**：固定三层典型局占格合法、无卡死出生位，大怪能推进；首轮无需发现流程即可交战，高墙挡弹但不隐藏单位，技能雾继续限制瞄准与观察，重试恢复开场基线。
- **主题拼接退出条件（待实施）**：同主题不同种子改变拼接、同种子完全复现；全部房间连通、连续 2×2 通路与双方出生位合法，房间内部尺寸和陈设不随机。

## 2. 远程直射、低墙掩护、舍身和借机（已交付）

- 远程直射跳过己方单位，不误伤；敌人、高墙及结界的阻挡不变。低墙挡步行，跳跃/飞行可越，不挡视线和弹道。仅玩家贴墙且从墙另一侧穿过的远程直击、直线法术减伤 25%；爆炸不受这项掩护。
- 弗兰克按完整基础移动距离走合法路径到援护位，代挡后留在当地；不读剩余步数、不算冲刺，不耗主辅、不触发借机、不接力舍身。复用已有动作导演、反应弹窗和反应费用机制。
- 借机覆盖双方：主动步行/冲刺逐步检查离开敌人占格外沿八邻域；原格按稳定顺序结算所有有额度者的基础近战。每单位开场有一次，本人自然行动开始刷新；受击者可反击一层，移动者失能则该步不发生。跳跃/瞬移/舍身/被推不触发。
- 已交付补充（`15daf9e`／`0fe3b32`）：正后总宽 45° 背袭（闪避−20、伤害×1.2）、反应折影步 2 米与主动折影步 5 米、六职业空间被动、施法者驻足／法力回响／棱镜中继、点卡声明蓄力后就绪选点；具体规则见 SPEC S03—S06。
- **退出条件**：定向用例能区分友军不挡枪、高墙挡枪、低墙方向性掩护；弗兰克能绕墙到位，超出可达路径则无候选；验证多个借机者、反击、移动截停及额度不能被再动刷新。

## 3. 可破坏地形、双跳和积极追击（已交付：bd35ead）

- 推动/击退共用阻挡与碰撞结算。撞高墙或站立单位时只伤被移动者，威力为未完成位移距离×10；撞低墙在墙前停、墙碎、威力减半。护甲与护盾照常。场景、渲染、寻路、范围与预览读同一份墙体变化。
- 爆炸或带【穿透】的直线攻击，单段有效原始伤害 >100 时可拆墙。按当前攻击属性、增减益及技能倍率，以 1.0 随机倍率计算；不读目标减免或实际掉血，多段不叠加。本段按出手时地形结算，再拆除有效覆盖里的低墙；空地可拆、被高墙拦住的格不拆；当段击破结界不溢入拆墙，下一段才读新状态；成组长椅／低墙只移除有效覆盖格。
- 显式精英/首领且为 2×2 的敌人首跳扣辅助行动，第二跳免费，两跳仅在同一自然行动使用。每次落地先震碎占格外沿八邻域的低墙，再对相邻敌友逐一套用完整重量门槛、力量对抗和向外推动距离。AI 考虑同伴被推的代价，积极选近战接敌或远程射击位；无合适攻击且追加移动有明确推进收益时，消耗主行动冲刺。
- **退出条件**：100 不拆、101 拆；同一攻击段先享受既有掩护，下一段立即获得破墙后的几何。双跳不吞第二个辅助动作、不跨自然行动；验证友敌落地对抗、撞停、冲刺推进及已可合理攻击时不会空跑。

## 4. 残血集火、Charge 格和地面意向（已交付：cac160c）

- 显式精英/首领或智慧敌人在本人自然行动开始检查无遮挡的残血者：发现半径为感知÷5 米、传令半径为其 3 倍。优先最低血量比例、同值更近；收报者保留最早的有效指令。低于 30% 才入选，回到 ≥30%、倒地/离场、发号者死亡即解除。技能雾里只追最后见处。已确认集火优先：命令可合法追击或攻击时不被正嘲讽目标抢走；无合法进路或动作才回到原选敌与嘲讽，回退不清令。
- 发令时从发号者指向目标画短暂血色线，被追踪者头顶挂红色准心，执行追踪的敌人亮现有眼睛图标，不另加入口。
- 敌方头像下沿用原版菱形充能格。`Charge` 是资源而非 `delay` 蓄力。充满当刻在当前合法覆盖中优先取命中人数最多、同人数取既有技能评分，地面只画一次实际形状的意向（如暴风雪圆区、维度撕裂直线带）；标明「施放时重选」。Boss 实际可先合法移位，再按最新位置重算，大招优先于集火；无合法命中或资源不足则留充能并正常作战，不锁旧圈、不强行空放。
- **退出条件**：抬血到线或发号者死亡时清标，技能雾不泄露实时坐标；玩家分散能减少大招命中人数，旧意向不追人，但正式释放使用新落点。一个 2×2 角色只算一个命中目标。

## 后续工作（基本战斗之后）

1. **地图制作与拼接**：逐主题确认恒定房间与连接口，实现合法拼接、2×2 连通和布阵；固定三层礼拜堂继续作规则回归基准。
2. **正式酒馆接入**：独立 iframe／正则传输、真实变量与 YAML 输入、同 ID 续载及战后 MMS 单写者回执；不改根回合制打包器。
3. **LLM 接入**：接通已有旁白／对话入口、角色发言和战后总结；生产提示词先送用户审核。LLM 不决定逐次移动、命中、伤害或敌方选招。

以上为后续方向，各轮实施范围仍须先确认，不把现有开关、测试接口或 Demo 当作正式接入。

## 主线之外与交付门禁

- 不做递归撞人、碰撞破防/打断、通用残血逃逸/狂暴，不恢复探索型多房间拓扑、场景迷雾、听力或通用巡逻任务；主题恒定房间拼接属于后续地图制作，不与此禁项混淆。独立 `delay` 规则不改；已有战斗目标、资源、时钟、结界与交付边界继续沿用。
- 每阶段仅跑相关组；稳定后于最终打包前跑唯一一次源码全量回归。重新执行 `node tactics/tools/build-demo-html.cjs`，产物验证关键模块入包、零外部 import、脚本闭合数量和本轮相关功能，再以当前单文件跑至少一条真实页面战斗流程。多文件源码全绿不代替此门禁。
- 正式酒馆接线仍须验独立 iframe/正则传输、同 ID 续载及战后 MMS 单写者回执；不提前改根回合制打包器，不把已有 Demo 当成正式酒馆发布。文档轮次不跑功能回归、不打包。
- 每阶段记录「核心目的 vs 现状」和已通过/失败/待验证项；新路线没有重新估算工时，不沿用旧估算。
