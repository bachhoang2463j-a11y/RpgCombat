# 战棋前端规则规格（已确认基线）

## 核心目的

创建独立的酒馆战棋前端：有限的视觉主题搭配可变地图与语义布阵；完全回合制、敏捷跑圈、逐角色立刻执行；延续原 RPG 标签、数值、反应、物品和旁白能力。用明确的空间规则支撑圆形头像、射界与枪械演出，而不是把自动播放视频当作可交互游戏。

## 具体任务

- 本规格记录本会话最终共识，优先于访谈中较早但已撤销的建议。
- 原项目 `index.html`、根目录 SPEC.md 与 README.md 不由本规格直接替换；新前端独立发布。
- 实现阶段与验证标准见 [PLAN.md](PLAN.md)，实际复用资源见 [RESOURCES.md](RESOURCES.md)。
- 状态：**规则已确认，功能未实现**。本轮只有文档和原型摘帧落盘。

<a id="s01"></a>
## S01. 范围、数据身份与运行环境

- 原 RPG 保留，战棋使用独立 HTML／酒馆正则产物及独立版本线；首版验收为桌面浏览器，不把手机触控算作已支持。
- UI 沿用原有行动轴、行动／技能菜单、编辑、记录与旁白入口，地图替换卡牌战场；不擅自新增页签或移动信息层级。
- `场景ID` 标识地图和物件变化；`战斗ID` 标识本场行动轴、限次和战斗状态。重复导入同一 ID 不重复生成场景。
- 同场景新战斗默认保留实际位置和门／物件变化，全员从零重新跑圈；明确 YAML 新配置仍有最高优先级。
- 初次初始化由场景规则和语义布阵生成位置；重试恢复本战斗保存的开场地图、站位和基线，不重新掷出更有利地形。
- 所有计算本地执行，LLM 不决定逐次移动、命中、伤害或敌方选招。原有旁白、角色气泡、智慧敌人和战后总结开关保留。

<a id="s02"></a>
## S02. 跑圈与全局事件时钟

- 一圈为 **10000 行动距离**。有效敏捷为当前基础敏捷加速度增减效果；正敏捷线性推进，下一次自然行动等待时间＝剩余行动距离÷有效敏捷。
- 敏捷100的正常整圈是100虚拟时间，敏捷200为50。无额外速度收益上限，不再通过 `[行动次数:N]` 机械追加轮次。
- 全图单位共享同一虚拟时间，初次开场从零进度起跑；远处单位照常巡逻／待机，不能仅因不在镜头内而冻结规则。
- 当前角色所有移动、主行动、辅助行动及反应链期间，全局时间冻结；现实思考、动画、网络旁白等待均不能改变跑圈进度。
- 换人时跳到最近的自然到轴或全局效果事件，不靠现实定时器逐帧驱动战斗。
- 途中变速保留已完成距离，仅按新敏捷推进后续距离。零速停跑，负值按零，不倒退。
- 同刻顺序：先周期效果应触发的最后一次结算，再状态到期／冷却解除／救援截止，最后让仍可行动的到轴角色取得行动权。
- 同刻多人到轴：基础敏捷更高者先；仍相同使用本战斗稳定单位顺序，不能受 DOM 顺序或读档次序影响。
- 新单位生成后立即占位、可成为目标，但从零跑完整圈才取得首个自然行动。原本就在地图上的单位加入接战不是新生成，不重置其进度。
- 若全部仍可参与的单位零速且没有未来事件能改变局面，本场以僵持结束；不是超时结束，也不偷偷恢复速度。
- UI 只显示当前可见敌人及友方，不暴露隐藏敌人的匿名轴项、人数或身份；内部调度仍完整。

## S03. 行动资源、再动与周期能力

- 每次自然行动：一份基础移动额度、**1主行动、1辅助行动**；自由穿插，允许移动—攻击—用余量撤回。
- 单次移动距离为独立属性；敏捷只提高自然行动频率，另通过已确认公式影响跳跃，不自动增加单次普通移动。
- 每消耗1主行动冲刺，追加一份本次基础移动额度，额外主行动也可用于冲刺。未用移动和行动点在本次行动结束时清除。
- 主动技能只分主／辅助行动，不新增通用零行动主动技。数值资源和物品消耗独立计算。
- 再动、多重施法、连动等原额外轮次能力改为额外主行动点，不刷新移动／辅助行动、不生成完整插队轮次。
- 当前正在行动的目标立即加点；其他目标保存到下次自然行动。每个“施术者＋技能”最多待领取1点；不同来源可叠加。同一再动技能本次自然行动只提供一次加点，避免自我返还循环。
- 原反击、反应、看破是事件链，不属于上述额外轮次；保留原触发、消耗、限次及化解机制，不新增统一反应额度；涉及他人时按技能距离、视野和遮挡检查。
- 不做借机攻击；首版不做警戒射击。移动不会因路过威胁区触发免费攻击。
- 主动等待只表示结束本次行动并正常跑下一圈，不保存本次轮次让到别人后面再回来。
- 防御姿态耗1主行动，保留原 MP／TP 恢复，持续100虚拟时间；同源重复施放刷新期限，不叠减伤。
- 原“大回合”周期回血／蓄能改为每100时间；原每大回合一次的机会改为触发后100时间才能再次取得。真实攻击后／受伤后等事件触发不改成定时触发。

<a id="s04"></a>
## S04. 隐藏方格、通行与移动

- 一格约1米；八方向移动，斜向成本按几何距离（约√2），不能从两格实障碍的夹角挤过去。
- 视觉平滑移动不等于连续坐标规则。落点、占位、视野和技能以统一的世界位置／占格数据计算，不读取头像 DOM 的显示坐标当规则位置。
- 普通移动可经过允许穿行的友方，不能停在其占地；敌方站立单位阻挡。大型单位的完整占格必须容纳于路径和落点。
- 倒地者、死亡遗体保留位置供救援或显示，但不挡普通移动和弹道。站起时若原位不合法，在附近寻找可容纳位置，不能挤开其他单位。
- 实墙、关闭实心门阻挡通行；低障碍只限制普通移动，需跳跃或闪现等能力越过。远程攻击默认越过低障碍，首版不做蹲下，也不再给低障碍附加早期提议的闪避加成。
- 跳跃耗1辅助行动和实际移动额度；最大跨度＝（当前有效敏捷＋力量）÷20米，可越低障碍、缺口和单位，不穿实墙或关门，落点合法且能容纳体型。
- 闪现／冲锋等位移技能按技能距离独立位移，只付声明的行动与数值资源，不扣普通移动。闪现只选本人当前可见合法落点；不经过中间通路，仍受结界的敌方跨界限制。
- 移动中首次发现新敌人立即停止，只扣已走距离；其余角色仍暂停，玩家可重新使用剩余资源。路径被真实占位阻断也不能继续穿行。
- 标记的门、机关、祭坛、油桶和部分物件可交互／破坏；普通建筑墙不全面可拆。开关门默认耗辅助行动，机关／任务交互默认主行动，可由场景明确覆盖；破坏走攻击成本。
- 第一版暂不实现危险地形伤害、坠落死亡或真实三维高度。已保留可跳越缺口不自动意味着已实现落坑结算。

## S05. 七种范围与技能结算

### 配置与含义

- 效果标签只描述作用，不再包含单／群人数语义：旧单体／群攻统一为伤害，单／群增、回、防等变体归一为增攻、回复、加防等规范效果。旧字符串在输入迁移时保真转换，规范编辑与导出不再使用单／群效果标签。
- 归一后的状态标签按"单X／X"区分时效：带"单"前缀（单避、回蓝等）为单次生效、用后即逝，不占Turns计时；不带前缀（回避、回复、增防等）为持久状态，按Turns或显式期限计时。反应技的瞬时效果采用"单"形态。
- 空间使用独立 `[范围:类型;参数]`，八种类型：**自身、单体、直线、扇形、圆形、全域、爆炸、召唤**。自身不需地图选点，整技默认只对施法者生效；其他范围由几何决定目标数量。圆形默认以自身为圆心，显式射程表示可将圆心投放至射程内指定点。召唤在指定射程内的空闲合法格生成新单位，落点须为空地且能容纳体型。
- 旧 `[他人]` 与单／群 Buff 信息仅供输入迁移为明确范围与目标取向，不能在结算中覆盖显式范围。攻击／减益默认选范围内敌方，有益效果默认选范围内友方。
- 多效果槽共用主要几何、射程与中心；明确自用的槽可以覆盖目标为施法者，不另建槽级几何。自身代价恒作用施法者。行动成本仍分主／辅助，协议示例不是生产提示词。
- 点单位、点方向、点地图中心决定施放；实时预览最终已知目标与实际作用区域，确认后才提交。范围、预览、执行和 AI 使用同一套查询。
- 单位占格中心进入范围即被选中；大型单位任意占格中心进入即作为一个目标，同技不因多格重复受击。

### 阻挡、命闪与特殊标签

- 敌对单体投射遇第一个站立角色停止；友方可挡弹但默认不受伤。单体有益作用不被中间角色截走，但默认需本人可见和合法射程。
- 直线、扇形、圆形、全域的范围作用不被单位截断；爆炸另有先投射后扩散的规则。**不新增穿人效果标签。**
- 【穿透】只无视护甲与个人护盾，不兼任穿人、穿墙、范围或破结界。
- 普通直射及范围传播受实墙阻挡；从作用中心向目标查墙体遮挡。全域明确忽略普通墙体和视距，结界仍可拦截。
- 【必中】跳过被动数值闪避，可绕过本人视野内普通阻挡抵达锁定目标；本人看不见的墙后目标不能借队友视野锁定。锁定后派生的范围仍查墙；不自动变成穿墙范围。
- 【必中】仍能被有效反应闪避、反应格挡、看破解除；护甲、个人盾、场地结界照常结算，破防仍需【穿透】。
- 【飞行】为移动增益状态：持有者单次基础移动额度＋50%，普通移动可跨过低障碍；不越实墙与关闭实心门，不改变跑圈频率。
- 空间可命中后执行数值命中、独立闪避及原反应体系。新增角色【闪避】属性，命闪中的防御侧基础值改读闪避，不再隐式读取敏捷；闪避增减仍属于闪避效果，速度增减只改变跑圈及已确认的跳跃公式。
- 旧角色缺【闪避】时，首次迁移用原基础敏捷初始化并保存为独立配置，之后提高Boss敏捷不会同步提高闪避；明确的职业条件加成须单独审计，不能把旧敏捷耦合藏在通用命闪公式里。新建角色按原型提供可编辑闪避初值，具体新建闪避数值表尚待实施前确认，不擅自编造。
- 每个伤害槽独立判命闪；被动闪避失败、确实将命中时才进入反应链。正式玩家控制角色自行选择反应或放弃，确认后扣费，放弃不扣；无自动确认倒计时。必中仍可被反应化解。单次反应不自动取消同技后续伤害槽。
- 附带减益复用该目标本技能至少一次攻击命中的结论；纯减益独立判定，有益效果与自身代价不随敌方攻击落空。普通直射被闪避后不再寻找后方新目标；显式转火按后续槽的合法目标另行处理。
- 默认伤害不误伤友方，有益效果只作用于相应友方；明确技能可以配置目标语义覆盖，但不能由演出偷偷决定。
- 【不分敌友】为显式目标语义覆盖标签：该范围效果对范围内所有单位（含施术者自身）同等生效，典型如造雾、致盲类范围减益；未标注时维持减益选敌、增益选友的默认取向。
- 允许向未知区域盲投合法方向或落点，不用预览、浮字、战报或旁白泄露隐藏目标。本人可见要求仍约束锁定【必中】及闪现。

### 【爆炸】

- 爆炸本身就是第六种范围，不需叠写单体＋爆炸，不是每个命中都递归产生第二次爆炸。
- 先投射到首次碰撞（角色、实墙等）或指定合法瞄准终点，再以接触点和配置半径扩散。
- 接触即爆，不先对接触者掷一次单体命闪；每个范围目标再独立判命闪／反应，主目标与其他目标默认都只承受一份爆炸伤害。
- 友方可能提前挡爆但默认不受伤；无碰撞在指定终点爆炸，不继续飞到最大射程。爆炸范围受实墙／结界规则限制。

### 一次操作的提交

- 预览、取消、非法落点不扣费；合法确认后一次支付行动与数值资源，并进入相应冷却，之后被化解不退费。
- 普通技能冷却从提交施放开始，按全局时间走；有冷却时同次额外主行动不能绕过冷却重放。
- 群体技能先确定目标，完成命闪／反应／伤害，再处理存活目标的强制位移。
- 已发出的技能即使施术者因真实反伤倒地仍完整结算，之后停止本角色后续操作；发出前被看破取消则无技能作用。
- 自身行动没有免死规则；HP消耗不足不能施放，但反伤、反击和物件爆炸可能让当前行动者倒地。

<a id="s06"></a>
## S06. 蓄力、专属加速库存与状态计时

- 蓄力N总主行动成本为基础1点＋N点额外准备，专属【加速】只替代N点准备，不替代基础使用点。
- **开始技能支付基础1主行动、MP／HP／TP／弹药／限次，启动冷却；释放不再支付主行动或重复资源。**
- 开始／继续时先扣角色共用加速库存，再自动投入当前可用主行动；准备中后续取得的主行动也自动投入，准备满就停止，多余主行动仍可使用。
- 专属库存只在本人确认开始／继续时扣，不能因队友轴外给予库存就自动释放。技能自身的【加速:N】在本次释放完成后到账，用于之后的准备。
- 移动、跳跃和辅助技能不因蓄力禁用。每次自然行动选择是否继续，不继续就取消；眩晕暂停，倒地或主动取消清空，已付资源不退款。一次仅准备一项技能。
- 准备满立即询问释放并选择当下合法目标，本次行动结束前释放或取消，不主动跨轮存好大招。库存足够也至少支付开始的1点主行动，不能零成本无限开火。
- 同一准备的后续继续／释放不被已经开始的自身冷却阻止；冷却约束下一次新准备。
- 普通限时效果与冷却以100时间＝1回合。同源（施术者＋技能）刷新强度／期限，不重复叠强度；不同来源可分开，显式叠层能力例外。
- 新施毒／燃烧的首跳在施加后100时间；同源重施保留原跳伤节拍，仅更新强度与到期，不能一直推迟首跳。
- 【眩晕】不带power参数，是否命中由本技Aim判定；命中后默认跳过下一次自然行动的全部资源，随后重跑一圈，不等于固定时间无法行动或停止跑圈。

<a id="s07"></a>
## S07. 场地结界（原肃正的新空间形态）

- 固定位置、固定大小，不跟随施术者；施放中心在本人可见、技能射程内，具体形状和尺寸由技能空间配置。
- 生成后独立存续：施术者倒地／离场不解除，直到耐久耗尽、配置时间结束或战斗结算。
- 友方可进出；敌方普通移动、跳跃、强制位移、闪现都不能跨界。可以完整圈住已有敌人，不自动推开；不能切过大型敌人占地，非法中心不得提交。
- 只拦截外部敌方对内部的攻击／减益；友方对外可以攻击。敌人在内部对内部攻击不被自动消除。
- 【必中】和【穿透】也被结界拦截。全域的敌方外到内作用同样受其保护规则约束。
- 所有边界共享一份耐久；可直接攻击结界，被拦的攻击转为打结界，减益本身不扣耐久。
- 同一范围攻击对同一结界只扣一次耐久，外部本来合法的目标照常结算；击破当次被拦部分不以溢出继续伤内部，之后攻击才能穿入。
- 每名施术者同时一座，新结界成功后替换旧结界；不同施术者结界首版不允许重叠／嵌套。
- 不复用原“全队伪目标＋群攻溢出平摊”的空间假设，但可复用耐久、护甲／克制与破碎反馈的已有结算和表现工具。

<a id="s08"></a>
## S08. 感知、视线、声音与信息边界

- 全向视野，半径＝当前感知÷5米；头像朝向独立表示瞄准，不要求每次转头。本人视野与友方共享视野区分保存。
- 整图地形公开；敌人实时位置须发现，离开视野只保留最后目击，不显示实时HP或行动轴项。
- 友方全队即时共享发现，但普通施放仍按本人视线／弹道；特殊跨墙支援必须明确技能规则。
- 实墙、关实心门、明确遮视物件阻挡视线；角色与低掩体默认不遮视。通行、挡弹、遮视是三个属性，不混成一项。
- 黑暗目标可发现距离为正常50%，夜视忽略黑暗；装饰光晕不参与逐像素规则。浓烟阻断经过它的视线。
- 声音沿房间／区域通路传播，使用通路长度与关门额外5米损耗；基础声距×感知÷50决定可听传播预算。感知50为基准，25减半，100翻倍，不设额外听距上限。
- 缺省基础声距：普通步行0、主行动冲刺6米、普通枪声40米、爆炸60米；技能／场景可显式覆盖。
- 听声只得到大概区域，不得到隐藏者名字、精确坐标或HP。敌方按小组和通讯能力共享，非通讯怪物不自动全图警觉。
- 丢失目标后调查最后线索区；无新线索回守位／巡逻，保留警觉，不跟踪真实隐藏位置。
- 盲投命中不自动揭示；不可见攻击者开火也不自动揭示。浮字、弹道可观察部分、战报和传给LLM的内容遵守同一已知情报边界。

<a id="s09"></a>
## S09. 敌方与友方AI

- 正式队员玩家控制，召唤物／临时盟友可配置玩家或AI。
- 决策用角色倾向＋当前行动候选评分：移动、攻击、辅助、治疗／增益、技能、掩护、任务行为；不做首版跨轮次多步协同推演。
- 候选基于AI自己的实际视听、记忆和合法空间，不能将引擎真实隐藏名册当作知情输入。
- 与玩家共用合法性／范围／伤害预测，再比较收益、风险、资源、状态重复和任务价值；新增熟悉效果槽不按技能名字逐项手写AI。
- 支持守区域／物件、巡逻、调查、抵达、撤退等通用任务；不要求自行理解任意剧情机关或编写任意任务链。
- 首版敌人归零走死亡／原复活流程，不新增敌方倒地互救。零HP友方失去仇恨，AI不能继续主动补刀。
- 新机制仍需动作处理和评分支持，不能声称标签化让AI自动理解无限类型的技能。

<a id="s10"></a>
## S10. 力量、推动、背运与倒地

- 力量、总重量用于推动和背运；重量为单一当前总值，包含身体及装备，不做逐件重量账本。
- 普通推动耗辅助行动，先要求目标重量严格小于力量×1.5，清醒敌人双方各掷1至力量、推动者严格更大才成功；自愿友方／倒地者免力量对抗。失败同样耗辅助行动，不再另掷命闪。
- 成功距离＝**2×floor（力量×1.5÷目标重量）米**，不另设最大距离；如力量40推重量50／30／15，分别2／4／8米。
- 技能命中后的击退／拉近按标签距离，免普通重量门槛和力量对抗；明确抗位移特性仍可生效。
- 碰实墙或站立角色停止，不连锁推人；未完成距离×10为碰撞原始威力，扣护甲和护盾，只伤被移动者。自然到达终点没有额外碰撞伤害。
- 群体向外位移先远后近，拉近先近后远，同距稳定顺序；后处理者遇已落位角色停止，不能重叠。
- 主角团归零倒地不死亡；临时盟友倒地后默认300时间救援，可显式覆盖；召唤物归零死亡。
- 所有倒地友方失去仇恨、不再受范围或持续伤害；原状态仍按时间到期，苏醒时未到期者继续存在。
- 倒地即退出行动轴，清除待领取额外主行动，终止当前剩余操作；治疗HP大于0即可救起，邻近主行动扶起到1HP。资源、冷却不刷新，救起从零跑圈。
- 只要仍有实际能救援的在场友方可以继续；已撤离者不计救援可能。无人能参与／救援则停止模拟并进入结果页。
- 一次背一人，总重量严格＜力量×1.5；背起耗主行动，合法放下免费，携带路段走1米扣2米移动额度，不因放下退费用或刷新额度。其他主／辅行动照常。
- 背运不暂停临时盟友倒计时；治疗醒来可停止濒死倒计时但仍被携带，合法放下才重新跑圈。携带者撤离可一起救出。
- 携带者失能原地解除携带，不加摔落伤害；醒者寻找附近合法落点，无容纳空间则等待腾出，不强行挪走他人。

<a id="s11"></a>
## S11. 场景目标、撤离与结果

- 配置击败指定小组、击杀首领、破坏目标、护送／抵达等场景目标；无关远端敌人不自动阻止结算。
- **当前角色结束行动后**检查目标，不在其还有资源时抢先截断；施术者倒地先完整收口已发技能并终止其轮次，再检查。
- 达成目标后显示结算按钮，自由决定继续救援／撤离或结算，不自动把人传送到出口。
- 任务结果与人员结果独立：目标已完成但全队失能可同时记录，不能抹掉已发生目标，也不能自动宣称全员安全。
- 撤离取代原平均速度对骰：实际抵达合法撤离区后逐人确认离场，不带走远处队友。
- 主动结束前列出未撤出、倒地、濒死人员并确认，原实际死亡按规则记录；不自动永久删除主角角色。
- 非致命保留原复活／自爆／制服顺序并适配空间；制服目标1HP、退轴不挡路。击败可接受制服，明确击杀任务不因制服完成。
- 每场限次、道具每场次数与一次性保命按新战斗ID刷新；继续同ID／新YAML不刷。库存型消耗品不能靠换战斗ID凭空补货。

<a id="s12"></a>
## S12. YAML、MMS、配置持久化与续载

- **YAML 显式字段最高优先级**，包括显式0、false、空值等合法表达，不能按真假值误当“未配置”。字段命名需在P01冻结，不私自扩大解析兜底。
- YAML缺配置时沿用原职责：可持久化角色配置（护甲等，默认启用、可关闭）；我方HP、MP和库存数量不另建前端长期档，从MMS读取。TP默认本场0，不扩展MMS。
- 源码旧 `persistAtk/Def/Spd` 强制覆盖YAML、`applyStatusBarRoster`直接覆盖数值是迁移审计点，不能作为新规则例外。
- 新YAML在当前已提交操作及反应链结束后应用，不在半次群攻中换掉对象；未给的新字段不无故重生成地图。
- 地图、对象变化、占位、行动进度、感知与任务等战术状态可按场景／战斗ID保存；关闭或切聊天冻结，不按现实时间追赶。
- **MMS仍仅战后同步**，不每行动上报。因此关闭重开后，资源重新从显式YAML或MMS取值，未结算资源变化不承诺精确断点续接；不能用战术存档偷偷保存另一份HP／MP／库存真值。
- 结算桥应适配独立战棋来源，继续使用事件／回执／幂等ID模式。具体跨前端结果键和MMS识别方式需P01/P11验证，不直接覆盖原RPG档。
- 结算后清空本场增减益、毒伤、冷却、蓄力、加速库存、未用点与结界；不由此恢复HP、MP、库存或倒地者。
- 重试恢复原开场基线，仍不直接回写MMS补货。角色配置编辑与本场战斗态使用独立草稿，不把实时数组交换成编辑副本。

### 我方角色配置导入／导出（新增确认）

- 入口位于现有**技能编辑器**，支持总体与单个角色，不新增顶栏入口或页签。
- 导出为带格式版本的JSON，包含角色配置、技能及组子技能、六种范围与行动成本、物品定义／绑定／用法、当前持久化属性及其开关；含独立闪避、力量、总重量、移动、感知、体型等新配置。
- 不包含HP／MP当前值、库存实时数量、TP当前值、当前护盾／Buff／冷却／蓄力／加速库存、场景地图与行动进度、API密钥。最大资源值、每场限次定义属于配置，可保留；库存数量来源仍为YAML／MMS，不能借导入制造资源档。
- 全体与单角色导入均按同名匹配：完整配置替换该角色草稿，新角色追加；不删除文件之外的已有角色，不按技能字段局部拼接旧角色。先展示导入结果，取消不生效，明确保存才持久化。
- 导入文件不是更高优先级的YAML：保存后只成为未被YAML显式配置字段的配置来源，YAML仍最高优先。
- 全体往返／单角色往返需验证组结构、范围、绑定、显式0、独立闪避和持久化开关不丢；不把DOM或函数JSON序列化成数据。

## S13. 表现与技术范围

- 二维正交俯视，深色地面与墙线、房间连通和局部光源；场景大小、通道和障碍不是写死的一张背景。
- 圆形头像始终正立，阵营色外环和独立朝向箭头；血量／资源就近呈现，不能通过画面暴露隐藏敌人信息。
- 射界、直线、圆形／爆炸作用预览与实际规则一致；枪口、弹道、命中火星、位移、倒地和破结界反馈优先复用已有工具。
- 镜头可平移、缩放及跟随当前动作，录像框和印章只是视觉参考，不强制复制视频剪辑、自动演播和装备插卡。
- 普通枪械只扣库存，不建弹匣、换弹、持武器切换；不同射击技能有合法资源就能使用。
- 原职业、技能效果、物品、召唤、变种、反应、复活、非致命及旁白逐类适配，不宣称所有旧字符串无需迁移。前后排、固定Act、多动衰减、旧撤退与伪全队屏障明确替换。
- 单HTML是分发形态，不代表开发必须把所有模块写在一个大文件。是否使用Phaser、ROT、Rex或Yuka以P00验证为准，不能为库改已定玩法。
- 不默认新增云资源、实时模型轮询或高频远程决策；不代替用户导入酒馆，不擅自开Chrome或模拟器。

## S15. 在开工阶段冻结的技术契约（不是新玩法）

1. P00固定库版本和浏览器适配，尤其Rex文档当前Phaser3／4混杂；先验证再选，不能默认最新版互相兼容。
2. P01冻结YAML字段、独立存档命名空间、同ID增量应用和MMS结果来源／回执；完整生产提示词仍须用户先审。
3. P03检查最后一跳／到期批次、速度Buff到期重算、复活入轴、周期被动与旧事件的映射，禁止用旧大回合重建器掩盖缺口。
4. P04冻结强制位移的8方向离散路径、墙面接触点和大型单位碰撞位置，验证最终中心／占格预览；不另加玩法距离上限。
5. P05若硬剧情关系无法满足则显示具体冲突而不是删人；软约束调整详情通过已有入口承载，如需新增入口先确认位置。
6. P07核验原反应链与部分状态逐类语义；P11核验只战后同步与续载资源重新读入对倒地／已支付蓄力的关联，不能默默改成每行动保存资源。
7. 技术验证发现已确认规则之间仍有不可消解冲突时，提交最小反例和建议由用户决定；不能在代码或测试夹具里偷偷选一个新默认。
