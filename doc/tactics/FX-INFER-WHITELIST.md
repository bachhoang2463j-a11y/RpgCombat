# 特效标签推断白名单（C1 草案 · 待审）

## 核心目的

LLM 生成的技能漏写或写错 `[特效:名]` 时，解析层就近给出合法演出，让临场生成的敌人"各有面貌"，同时不把角色/道具专属演出错配给无关技能。只改 `fxTag`，不改任何规则字段。

## 具体任务

1. 审定下表"可推断"与"永不推断"的划分、关键词与升档条件。
2. 审定后实现 `fx-infer.mjs`（纯函数）+ 编辑器「（推断）」标注 + 定向用例；推断表同时可贴进生成提示词。

---

## 一、决策顺序

1. 显式 `[特效:无]` → 保持无演出，不推断。
2. 显式名合法 → 原样使用。
3. 显式名不合法 → 先查**别名表**，再按"合法名包含于显式名 / 显式名包含于合法名"就近纠正（只在**可推断**集合内纠正）。
4. 未写 → 按**技能名 + 状态标签**的元素关键词推断（第三节）。
5. 关键词全未命中 → 按**范围 × 伤害类型**兜底（第四节）。
6. 仍无 → 现有通用兜底 `neutral-impact`。

推断结果写入 `skill.fxTag` 并标 `fxTagInferred: true`；编辑器下拉显示「名称（推断）」，玩家可改。

| 档 | 合法名 | 说明 |

| 中档（L1/L2） | 水流 · 诅咒 · 独头弹 · 枪击穿透 · 远程重击 · 近战重击 · 冲锋 · 咆哮 · 单体回复 · 群体回复 · 群体增益 · 群体减益 · 再动加速 | 有明确语义才推断（见关键词） |
