# RULES02 原版底层规则接入

## 核心目的

在 FX01 `13aacdd` 之上接入原版数值、三个自由效果槽、费用、职业、变种和玩家反应选择，消除“只解析/只显示=已迁移”的完成口径。舍身与场地结界经用户明确暂缓。

## 具体任务

1. 效果标签与空间分离，单/群变体归一；增加自身作为第七范围。
2. 公共几何决定范围，各槽按敌我取向分流；明确自用槽可覆盖为自身，不增加另一套几何。
3. 伤害槽逐槽命闪、反应、威力与扣盾扣血；附带减益共享至少一次攻击命中，有益槽和自身代价不受该门控。
4. 原版纯数值与事件钩子适配独立闪避、主辅行动和100虚拟时间；不恢复前后排、Act、多动衰减或全队伪屏障。
5. 正式玩家反应在将命中时弹窗选择，确认后扣费、放弃不扣；单次回避不能自动取消同技能其余伤害槽。
6. 物品、弹药、恢复、防御、召唤与普通技能共用规则入口；演出只消费结果。
