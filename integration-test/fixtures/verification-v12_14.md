# v12.14 限时赋予验收

日期：2026-11-17。

## 核心目的

通过敌我通用的 `[赋予:xx]` 技能标签，让目标限时拥有已有变种能力，到期仅移除临时层，不污染原生能力与角色存档。

## 具体任务与已确认语义

- 12个支持名：流体、虚形、破法、要害、防火、耐毒、钢体、再生、狂暴、吸血、荆棘、复活。
- 不包含智慧、蜕皮、连动、自爆；不新增群赋予。
- 赋予占一个效果槽，power为0；持续回合取槽位 `;turns:N` → 技能 `[Turns:N]` → 默认3。
- 无 `[他人]` 自施；有 `[他人]` 可选择同阵营目标，包含召唤物。混合攻击技能的赋予给自身，不给被攻击的对手。
- 同名赋予不叠强度，回合取剩余与新时长的最大值；不同特性并存。每大回合持有者首次行动递减一次，额外行动不扣。
- 原生与临时复活共用本场一次机会，30%最大HP复活并清Buff/护盾；本场消费标记不随重施、外部治疗或临时Buff清除恢复。到期未触发则失去临时资格；新战局/重置恢复。
- 临时免疫只阻止之后施加的毒、燃烧、眩晕，不主动清已有状态。
- UI复用旧标签下拉、槽位回合输入和角色Buff栏；显示“赋予·虚形”“虚形·N回”，赋予槽威力控件禁用。

完整技能示例：

```text
【灵风术】[单避;power:50][单速;power:30][赋予:虚形][Turns:10][MP:10][法术][特效:灵风术][限1次]
```

三个效果均持续10回合，扣10MP、本场限一次；希望选择队友时再附加 `[他人]`。

## 实现范围

- `index.html`：三槽解析（技能与物品共用）、赋予handler、原生/临时查询、抗性/免疫/狂暴/再生/吸血/荆棘/复活、双方AI/目标路由、预览/普通反击/强力反击、Buff展示及旧编辑器控件联动。
- 临时记录 `{type:'variant',variant:'虚形',value:1,duration:N}`，不改原生tags/resistMap/immune字段。

- 战报摘要只增加赋予和复活已耗尽两条规则，不修改任何LLM提示词或调用频率。
- 新fixture与产物专项接入harness第61组；旧抗性探针对齐共享查询，数值预期不改。
